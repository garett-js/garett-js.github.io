Как работает Flutter?

Особенность Flutter заключается в том, что приложения для разных платформ могут использовать один и тот же код. Конечно, некоторые части кода необходимо адаптировать под конкретную операционную систему, например, iOS, но большая часть кода остается неизменной.

Это позволяет разработчикам значительно экономить время и ресурсы при создании приложений. Благодаря сверхбыстрому рендерингу, Flutter-приложения работают так же быстро, как нативные приложения (обещают до 120fps)

Функции Flutter не зависят от нативных функций, так как при разработке используются собственные элементы UI называемые виджетами. Flutter умеет работать с нативным кодом, если есть в этом необходимость.

Функция hot reload

Киллер фича для разработчиков hot reload - запущенное приложение автоматически обновляется с изменениями кода и его сохранении! Без постоянной пересборки (build) приложения и бесконечного ожидания!

Декларативный стиль разработки

Разработка на Flutter представляет собой декларативный стиль - это очень похоже на веб-разработку, например HTML CSS XML

Другие декларативные фреймворки React , Jetpack Compose , SwiftUI

Язык программирования Dart

  • Для разработки под Flutter мощный и современный язык программирования Dart.
  • Он легок в освоении и позволяет создавать эффективные приложения.
  • Dart использует виртуальную машину (VM)
  • Благодаря этому мы используем крутую фичу - горячую перезагрузку.

Виртуальная машина (VM)

Это программное обеспечение, которое создает виртуальную среду для запуска программ, как если бы они работали на реальном устройстве.

Она используется для выполнения кода независимо от операционной системы.

Историческая справка

Изначально Flutter был создан с целью повышения производительности веб-приложений.

Для разработки на Flutter разработчики выбрали язык Dart, также разработанный компанией Google, благодаря его высокой производительности и скорости, а также наличию виртуальной машины. Dart имеет строгую типизацию, поддерживает объектно-ориентированное, реактивное и асинхронное программирование, что даёт ему значительные преимущества перед JavaScript.

Важную роль играет графический движок Skia, ещё один открытый проект от Google.
Skia работает напрямую с GPU через Vulkan на Android и Metal на iOS, что обеспечивает быструю и стабильную графику на мобильных устройствах. Этот API позволяет виджетам Flutter быстро и стабильно отображаться на любой платформе.

В настоящее время Flutter переходит на новый движок — Impeller, который обеспечивает ещё более высокую производительность и стабильность. Начиная с версии Flutter 3.10, Impeller используется по умолчанию для всех iOS-приложений.

Установка Flutter SDK на Windows

Чтобы начать разработку с использованием Flutter, необходимо установить SDK. Вот как это сделать на Windows:

1. Установка Git for Windows:

  • Перейдите на сайт https://git-scm.com/download/win и скачайте Git for Windows.
  • Установите Git, следуя инструкциям на экране.

2. Установка Android SDK:

  • Самый простой способ установить Android SDK это установить Android Studio, которая включает все необходимые инструменты.
  • https://developer.android.com/studio?hl=ru

3. Загрузка Flutter SDK:

  • Перейдите на страницу https://flutter.dev/docs/get-started/install/windows
  • Найдите ссылку на zip-архив с Flutter SDK в секции Install the Flutter SDK
  • Скачайте и распакуйте архив в папку C:\flutter

4. Добавление Flutter в переменные среды:

Пишем путь до директории где находится Flutter в данном случае c:\flutter\bin 

  • Откройте "Изменение переменных среды текущего пользователя" через поиск.
  • В окне переменных среды найдите переменную Path и нажмите "Изменить".
  • Нажмите "Создать" и введите путь к папке bin в Flutter SDK, например, C:\flutter\bin

5. Проверка установки:

  • Откройте командную строку и введите команду flutter.

Если Windows распознает команду и выводит справочную информацию, Flutter установлен и настроен правильно.

Обновление Flutter SDK

flutter upgrade - команда в консоли для обновления Flutter. Поскольку он активно развивается, то лучше обновляться регулярно.

flutter doctor - проверить окружение на правильную настройку
