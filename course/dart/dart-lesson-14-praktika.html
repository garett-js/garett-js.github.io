Практические задания - Урок 14: Классы и Объекты

Инструкция: Решите все задания по порядку. Создайте отдельный файл .dart для каждой задачи или решите все в одном файле, разделяя задачи комментариями.

Задача № 1: Класс Student

Создайте класс Student, который представляет собой студента.

Класс должен включать:

  • Свойства: name (имя), age (возраст), grades (список оценок).
  • Конструктор, который инициализирует эти свойства.
  • Метод info(), который показывает информацию про студента.
  • Метод calculateAverageGrade(), который вычисляет среднюю оценку студента.

Создайте несколько объектов студентов, вызовите свойства и методы.

Дополнительно: добавьте собственные свойства и методы.
