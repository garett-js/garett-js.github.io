Как добавить к приложению свою иконку? 

Размеры иконки должны соответствовать определённым требованиям. Проще всего воспользоваться сервисом для создания иконок https://appicon.co/

Например для Android устройств:

  • Оставить галку для Android, перетащить картинку, нажать кнопку Generate.
  • Скачать архив
  • Из архива достать файлы из папки Android
  • Скопировать по пути название_вашего_проекта/android/app/src/main/res
  • Заменить старые папки на новые.
