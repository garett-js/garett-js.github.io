Решения - Урок 5: Условные конструкции

Внимание! Сначала попробуйте решить задачи самостоятельно. Эти решения предназначены для проверки или если вы совсем застряли.

Задача № 1: Проверка здоровья персонажа

Решение

import 'dart:io';

void main() {
    print("Введите здоровье персонажа:");
    int health = int.parse(stdin.readLineSync()!);

    if (health == 100) {
        print("Персонаж полностью здоров");
    } else {
        print("Персонажа нужно подлечить");
    }
}

Объяснение: Простая конструкция if-else. Проверяем точное равенство здоровья 100, иначе выводим сообщение о необходимости лечения.

Задача № 2: Классификация монстра

Решение

import 'dart:io';

void main() {
    print("Введите здоровье монстра:");
    int monsterHealth = int.parse(stdin.readLineSync()!);

    if (monsterHealth > 100) {
        print("Босс");
    } else if (monsterHealth > 50) {
        print("Элитный монстр");
    } else {
        print("Обычный монстр");
    }
}

Объяснение: Конструкция if-else if-else. Важен порядок проверки условий - сначала проверяем большее значение (>100), затем меньшее (>50). Если ни одно не подходит, значит здоровье ≤ 50.

Задача № 3: Система оповещения социальной сети

Решение

import 'dart:io';

void main() {
    print("Введите количество подписчиков:");
    int subscribers = int.parse(stdin.readLineSync()!);

    if (subscribers > 10000000) {
        print("Вау! Ну тут уже только ЗОЛОТО! 💕");
    } else if (subscribers > 100000) {
        print("Шикарно! Вручаем вам Серебряную кнопку! 👌");
    } else if (subscribers > 1000) {
        print("У вас уже крутой канал, но кнопку ещё не дадим! 😊");
    } else {
        print("Хммм...Трудитесь усердней и всё у вас получится!");
    }
}

Объяснение: Важно начинать проверку с самого большого числа, так как условия проверяются по порядку.

Задача № 4: Время работы Кванториума

Решение

import 'dart:io';

void main() {
    print("Введите время (0-23):");
    int time = int.parse(stdin.readLineSync()!);

    if (time == 12) {
        print("Кванториум закрыт (обеденный перерыв)");
    } else if (time >= 8 && time <= 18) {
        print("Кванториум работает");
    } else {
        print("Кванториум закрыт");
    }
}

Объяснение: Сначала проверяем особый случай (обед в 12 часов), затем проверяем рабочие часы (8-18).

Задача № 5: Определение четверти часа

Решение

import 'dart:io';

void main() {
    print("Введите минуты (0-59):");
    int minutes = int.parse(stdin.readLineSync()!);

    if (minutes >= 0 && minutes <= 14) {
        print("Первая четверть часа");
    } else if (minutes >= 15 && minutes <= 29) {
        print("Вторая четверть часа");
    } else if (minutes >= 30 && minutes <= 44) {
        print("Третья четверть часа");
    } else if (minutes >= 45 && minutes <= 59) {
        print("Четвертая четверть часа");
    } else {
        print("Неверное значение минут!");
    }
}

Объяснение: Проверяем диапазоны для каждой четверти с помощью if-else if-else.

Задача № 6: Определение времени года

Решение (if-else if-else)

import 'dart:io';

void main() {
    print("Введите номер месяца (1-12):");
    int month = int.parse(stdin.readLineSync()!);

    if (month == 12 || month == 1 || month == 2) {
        print("Зима");
    } else if (month >= 3 && month <= 5) {
        print("Весна");
    } else if (month >= 6 && month <= 8) {
        print("Лето");
    } else if (month >= 9 && month <= 11) {
        print("Осень");
    } else {
        print("Неверный номер месяца!");
    }
}
Решение (switch-case)

import 'dart:io';

void main() {
    print("Введите номер месяца (1-12):");
    int month = int.parse(stdin.readLineSync()!);

    switch (month) {
      case 12:
      case 1:
      case 2:
        print("Зима");
        break;
      case 3:
      case 4:
      case 5:
        print("Весна");
        break;
      case 6:
      case 7:
      case 8:
        print("Лето");
        break;
      case 9:
      case 10:
      case 11:
        print("Осень");
        break;
      default:
        print("Неверный номер месяца!");
    }
}

Объяснение: Задача решена двумя способами: с помощью if-else if-else и более элегантно с switch-case, используя "проваливание" (fall-through) для группировки месяцев.

Задача № 7: Доступ к локации

Решение

import 'dart:io';

void main() {
    print("Введите ваш социальный ранг:");
    String socialRank = stdin.readLineSync()!.toLowerCase();

    print("Есть ли у вас пропуск? (y/n):");
    bool hasPass = stdin.readLineSync()!.toLowerCase() == 'y';

    if (socialRank == "дворянин" || hasPass) {
        print("Доступ разрешен! Добро пожаловать в Замок!");
    } else {
        print("Доступ запрещен! Вам нужен пропуск или дворянский титул.");
    }
}

Объяснение: Используем логический оператор || (ИЛИ) - достаточно выполнения одного из условий. Метод .toLowerCase() используется для обработки ввода пользователя независимо от регистра.
