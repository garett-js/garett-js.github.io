Решения - Урок 6: Остаток от деления. Инкремент и Декремент

Внимание! Сначала попробуйте решить задачи самостоятельно. Эти решения предназначены для проверки или если вы совсем застряли.

Задача № 1: Расход маны

Решение
import 'dart:io';

void main() {
  print("Введите количество маны:");
  int manaPoints = int.parse(stdin.readLineSync()!);
  int spellCost = 25;

  print("До каста: $manaPoints маны");

  // Используем комбинированный оператор для уменьшения маны
  manaPoints -= spellCost;

  print("После каста: $manaPoints маны");

  if (manaPoints >= 0) {
    print("Заклинание успешно применено!");
  } else {
    print("Недостаточно маны для заклинания!");
  }
}

Объяснение: Используем комбинированный оператор -= который эквивалентен manaPoints = manaPoints - spellCost. Это более краткая и читаемая запись.

Задача № 2: Усиление оружия

Решение
import 'dart:io';

void main() {
  print("Введите количество побед:");
  int winCount = int.parse(stdin.readLineSync()!);

  print("Победы: $winCount");

  // Проверяем, делится ли количество побед на 3 без остатка
  if (winCount > 0 && winCount % 3 == 0) {
    print("Оружие усилено! (каждая 3-я победа)");
  } else {
    // Вычисляем, сколько побед осталось до следующего усиления
    int remaining = 3 - (winCount % 3);
    print("Оружие не усилено. До усиления осталось: $remaining победы");
  }
}

Объяснение: Оператор % (модуло) возвращает остаток от деления. Если winCount % 3 == 0, значит число побед делится на 3 нацело, и оружие усиливается.

Задача № 3: Последние цифры ID предмета

Решение
import 'dart:io';

void main() {
  print("Введите ID предмета:");
  int itemId = int.parse(stdin.readLineSync()!);

  print("ID предмета: $itemId");

  // Получаем последние 3 цифры с помощью остатка от деления на 1000
  int last3Digits = itemId % 1000;

  // Форматируем с ведущими нулями для красивого вывода
  String formatted = last3Digits.toString().padLeft(3, '0');
  print("Последние 3 цифры: $formatted");
}

Объяснение: itemId % 1000 дает остаток от деления на 1000, что и есть последние 3 цифры. Метод padLeft(3, '0') добавляет ведущие нули, если число меньше 3-х значного.

Задача № 4: Проверка числа на условия

Решение
import 'dart:io';

void main() {
  print("Введите число:");
  int number = int.parse(stdin.readLineSync()!);

  // Проверяем два условия одновременно
  bool isOdd = number % 2 != 0;
  bool isDivisibleBy7 = number % 7 == 0;

  bool result = isOdd && isDivisibleBy7;

  print("Число $number является нечетным и делится на 7: $result");
}

Объяснение: Используем логический оператор && для проверки двух условий одновременно. Число нечетное, если number % 2 != 0, и делится на 7, если number % 7 == 0.

Задача № 5: Счастливый билет

Решение
import 'dart:io';

void main() {
  print("Введите 6-значный номер билета:");
  String? ticket = stdin.readLineSync();

  if (ticket != null && ticket.length == 6 && int.tryParse(ticket) != null) {
    // Разделяем на две половины
    String firstHalfStr = ticket.substring(0, 3);
    String secondHalfStr = ticket.substring(3);

    // Вычисляем суммы
    int sumFirst = firstHalfStr.split('').map(int.parse).reduce((a, b) => a + b);
    int sumSecond = secondHalfStr.split('').map(int.parse).reduce((a, b) => a + b);

    // Проверяем равенство сумм
    if (sumFirst == sumSecond) {
      print("Да: $sumFirst равно $sumSecond");
    } else {
      print("Нет: $sumFirst не равно $sumSecond");
    }
  } else {
    print("Ошибка: введите ровно 6 цифр!");
  }
}

Объяснение: Используем substring для разделения строки. Затем split('') превращает строку в список символов, map(int.parse) преобразует их в числа, а reduce() суммирует.

Задача № 6: Размен монет для великого воина

Решение
import 'dart:io';

void main() {
  print("Введите стоимость услуг:");
  int amount = int.parse(stdin.readLineSync()!);
  
  List<int> denominations = [25, 15, 10, 1];
  int totalCoins = 0;

  print("\nРазбивка:");

  for (int coin in denominations) {
    if (amount >= coin) {
      // Вычисляем количество монет данного номинала
      int count = amount ~/ coin;
      totalCoins += count;
      print("$count монет номиналом $coin = ${count * coin}");
      
      // Уменьшаем оставшуюся сумму
      amount %= coin;
    } else {
        print("0 монет номиналом $coin = 0");
    }
  }

  print("\nМинимальное количество монет: $totalCoins");
}

Объяснение: Используем жадный алгоритм - берем максимально возможное количество монет самого крупного номинала, затем переходим к следующему. Оператор ~/ дает целое количество монет, а %= обновляет остаток.
