Что такое Flutter?

Это мощный UI фреймворк от компании Google, который позволяет создавать кроссплатформенные и мультиплатформенные приложения, используя одну и ту же кодовую базу.

Это означает, что можно создавать приложения, которые работают на платформах:

  • Android, iOS, Аврора ОС
  • Windows, macOS, Linux
  • Web

При сильном желании можно запустить на cмарт-часы, навигаторы и smart TV

Software Development Toolkit SDK

Это готовый набор инструментов для разработки программного обеспечения

Нативная разработка

Без такого кроссплатформенного решения, для каждой отдельной платформы приходится писать приложения на своих родных (нативных) технологиях.

 

Как работает Flutter?

Особенность Flutter заключается в том, что приложения для разных платформ могут использовать один и тот же код. Конечно, некоторые части кода необходимо адаптировать под конкретную операционную систему, например, iOS, но большая часть кода остается неизменной.

Это позволяет разработчикам значительно экономить время и ресурсы при создании приложений. Благодаря сверхбыстрому рендерингу, Flutter-приложения работают так же быстро, как нативные приложения (обещают до 120fps)

Функции Flutter не зависят от нативных функций, так как при разработке используются собственные элементы UI называемые виджетами. Flutter умеет работать с нативным кодом, если есть в этом необходимость.

Функция hot reload

Киллер фича для разработчиков hot reload - запущенное приложение автоматически обновляется с изменениями кода и его сохранении! Без постоянной пересборки (build) приложения и бесконечного ожидания!

Декларативный стиль разработки

Разработка на Flutter представляет собой декларативный стиль - это очень похоже на веб-разработку, например HTML CSS XML

Другие декларативные фреймворки React , Jetpack Compose , SwiftUI

Язык программирования Dart

  • Для разработки под Flutter мощный и современный язык программирования Dart.
  • Он легок в освоении и позволяет создавать эффективные приложения.
  • Dart использует виртуальную машину (VM)
  • Благодаря этому мы используем крутую фичу - горячую перезагрузку.

 

Виртуальная машина (VM)

Это программное обеспечение, которое создает виртуальную среду для запуска программ, как если бы они работали на реальном устройстве.

Она используется для выполнения кода независимо от операционной системы.

Историческая справка

Изначально Flutter был создан с целью повышения производительности веб-приложений.

Для разработки на Flutter разработчики выбрали язык Dart, также разработанный компанией Google, благодаря его высокой производительности и скорости, а также наличию виртуальной машины. Dart имеет строгую типизацию, поддерживает объектно-ориентированное, реактивное и асинхронное программирование, что даёт ему значительные преимущества перед JavaScript.

Важную роль играет графический движок Skia, ещё один открытый проект от Google.
Skia работает напрямую с GPU через Vulkan на Android и Metal на iOS, что обеспечивает быструю и стабильную графику на мобильных устройствах. Этот API позволяет виджетам Flutter быстро и стабильно отображаться на любой платформе.

В настоящее время Flutter переходит на новый движок — Impeller, который обеспечивает ещё более высокую производительность и стабильность. Начиная с версии Flutter 3.10, Impeller используется по умолчанию для всех iOS-приложений.

Установка Flutter SDK на Windows

Чтобы начать разработку с использованием Flutter, необходимо установить SDK. Вот как это сделать на Windows:

1. Установка Git for Windows:

  • Перейдите на сайт https://git-scm.com/download/win и скачайте Git for Windows.
  • Установите Git, следуя инструкциям на экране.

2. Установка Android SDK:

  • Самый простой способ установить Android SDK — это установить Android Studio, которая включает все необходимые инструменты.
  • https://developer.android.com/studio?hl=ru

 

3. Загрузка Flutter SDK:

  • Перейдите на страницу https://flutter.dev/docs/get-started/install/windows
  • Найдите ссылку на zip-архив с Flutter SDK в секции Install the Flutter SDK
  • Скачайте и распакуйте архив в папку C:\flutter

  1. Добавление Flutter в переменные среды:

    Пишем путь до директории где находится Flutter в данном случае c:\flutter\bin 

    • Откройте “Изменение переменных среды текущего пользователя” через поиск.
    • В окне переменных среды найдите переменную Path и нажмите “Изменить”.
    • Нажмите “Создать” и введите путь к папке bin в Flutter SDK, например, C:\flutter\bin

  2. Проверка установки:

    • Откройте командную строку и введите команду flutter.

Если Windows распознает команду и выводит справочную информацию, Flutter установлен и настроен правильно.

Создание и запуск нового Flutter проекта

Создать Flutter проект можно несколькими способами, разберем их все.
Вы в итоге пользуйтесь тем который больше понравится.

Создание проекта через Терминал

  • Сначала нужно создать папку на компьютере, где вы будете хранить все Flutter проекты. Например в корне диска С: или на рабочем столе. Называем папку Dev
  • Открываем любой терминал, которым вы пользуетесь: стандартный windows, Git console, терминал через VS Code, iTerm и т.д.
  • Переходим в терминале с помощью команды cd в созданную вами папку Dev

  • Пишем в терминале такую команду для создания нового Flutter проекта
flutter create flutter_course

  • Немного ждём пока создается проект, после переходит в папку созданного проекта и открываем проект внутри VS Code с помощью этих команд
cd flutter_course
code .

  • В итоге откроется VS Code с только что созданным новым Flutter проектом

Создание проекта через VS Code

  • Открываем пустой VS Code
  • Находим в верхнем меню команду View --> Command Pallete…

 

  • Пишем слово flutter и выбираем пункт Flutter: New Project

 

  • Выбираем тип приложения, в данном случае нажимаем на Application

​​​​​​

  • Указываем папку, где будет хранится проект
  • Нажимаем на кнопку Select a folder to create the project in
  • Далее указываем название нашего приложения, например flutter_course
  • В итоге будет создан новый Flutter проект

Первый запуск Flutter проекта

Можно заметить, что был сгенерирован целый демонстрационный проект. Прежде чем разбираться со структурой проекта, который видно с левой стороны, где куча папок и файлов, давайте проверим запускается ли наш проект.

Для этого сначала нужного выбрать целевую платформу, на которой будем запускать приложение.

Запуск приложения

Чтобы запустить приложение, нужно

  • либо нажать клавишу F5 на клавиатуре

  • либо найти в коде функцию main(), над ней три кнопки Run | Debug | Profile Нажимаем Run
  • либо нажать на кнопку треугольник сверху-справа

Панель управления

Обратите внимание! Когда мы запускаем на выполнение приложение, внутри VSCode появляется такая дебаг панель, с помощью которой удобно осуществлять управление:

  • Иконка молнии это HOT RELOAD
  • Иконка зеленой стрелки это HOT RESTART

  • Иконка синей лупы это инспектор виджетов
  • Первые четыре иконки которые сейчас серые, нужны для дебага приложения

Структура Flutter проекта

Когда мы создали новый Flutter проект, то слева появились просто куча непонятных файлов и папок. Главное сейчас не испугаться этого :) Там всё на самом деле просто. Сейчас сделаем обзор на структуру проекта

Обзор структуры Flutter проекта

  • android, ios, linux, macos, web, windows – директории со стартовыми настройками и кодом для запуска приложения на одной из этих платформ.
  • build – соответственно билды (готовые приложения для запуска) и кэш проектов
  • test – тесты для проекта
  • lib – наша основная рабочая директория, в ней находятся исходники с кодом на языке dart, которые мы будем писать.
  • Файл pubspec.yaml – конфигурационный файл проекта, содержит различные настройки проекта.

Откроем файл pubspec.yaml здесь находится мета информация о нашем проекте и самое главное зависимости (dependencies), которые мы можем устанавливать в наш проект, т.е. это код от других разработчиков.

name: flutter_kvant_app
description: "A new Flutter project."
publish_to: 'none'

version: 1.0.0+1

# Версия языка программирования Dart
environment:
  sdk: 3.6.1

# Зависимости - дополнительные сторонние библиотеки
dependencies:
  flutter:
    sdk: flutter
  cupertino_icons: ^1.0.8

# Зависимости только на время разработки
dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: 5.0.0

# Настройка flutter пакетов (доступ к material иконкам, изображениям, шрифтам)
flutter:
  uses-material-design: true

Важно запомнить!

Обязательное условие, для правильной работы конфигурационного файла, делать отступы в 2 пробела для вложенных элементов

Будем работать с Git + GitFlic (GitHub)

1. Откройте терминал в корне проекта и введите следущие команды

git config --global user.name "ТВОЙ USERNAME"
git config --global user.email "ТВОЙ EMAIL"

Вместо ТВОЙ USERNAME пишем свой реальный user.name
Вместо ТВОЙ EMAIL пишем свой реальную почту

git init
git add .
git commit -m "Initial commit"

2. Создаём новый репозиторий на GitFlic или GitHub

Подлючаем его в свой проект и делаем пуш

git remote add origin https://gitflic.ru/project/ТВОЙ_АККАУНТ/course_2025.git
git push -u origin master

Эту ссылку origin https://gitflic.ru/project/ТВОЙ_АККАУНТ/course_2025.git вы должны получить сами на сайте GitFlic или GitHub
