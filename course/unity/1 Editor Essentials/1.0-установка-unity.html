1.0 - Установка Unity

Что такое Unity Hub и Unity Editor?

Для работы с Unity вы начнете с Unity Hub.

Unity Hub — это отдельное приложение, которое упрощает навигацию, загрузку и управление вашими проектами и установками Unity.​
Из Hub вы будете загружать и управлять различными версиями Unity Editor.

Unity Editor это приложение, в котором вы будете создавать 3D или 2D миры и разрабатывать свои интерактивные приложения.​

Системные требования

Убедитесь, что компьютер, который вы используете, соответствует минимальным требованиям к оборудованию для запуска Unity. Обычно, если у вас есть ПК под управлением Windows или Mac под управлением macOS, приобретенный за последние несколько лет, ваш компьютер, вероятно, готов для Unity. Unity также работает на Linux.​

Unity не будет работать на Chromebook или планшете.​

Загрузка и установка

Если у вас еще нет Unity, установленного на вашем компьютере, используйте приведенные ниже инструкции для загрузки Unity Hub и установки Unity Editor :​

  1. Перейдите на страницу загрузки Unity - https://unity.com/ru/download

  2. В разделе Download the Unity Hub выберите вариант для вашей операционной системы. Будет загружен файл с именем UnityHubSetup. Это имя файла может отличаться в зависимости от версии Hub и вашей операционной системы.​

  3. Найдите и запустите ранее загруженный файл UnityHubSetup.​

  4. Следуйте инструкциям для вашей платформы для установки Unity Hub.​

    Если вы еще не настроили свою учетную запись Unity, вам будет предложено сделать это в процессе установки.​

    Как только вы окажетесь в Unity Hub, он направит вас к установке последней версии долгосрочной поддержки (LTS) Unity Editor. Каждая версия LTS — это наша самая последняя, полностью протестированная версия.​

  5. Выберите Install Unity Editor для загрузки и установки последней версии LTS Unity Editor.

Установка нужной версии Unity

  1. В Unity Hub выберите вкладку Installs​
  2. Выберите кнопку Install Editor для установки новой версии.
  3. В разделе Unity 6 releases выберите кнопку Install для вашей платформы.[​
  4. На странице Add modules выберите доступную опцию в разделе DEV TOOLS для установки совместимого приложения для программирования.​
  • В Windows выберите Visual Studio Community 2022.​

    Установка одного из этих инструментов позволит вам более эффективно писать и отлаживать код для ваших проектов Unity.​
  1. Выберите кнопку Continue для продолжения установки.​
