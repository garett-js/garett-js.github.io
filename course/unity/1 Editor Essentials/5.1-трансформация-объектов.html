5.1 - Трансформация объектов

В окне Иерархия нажимаем ПКМ -> 3D Object и выбираем по очереди нужные элементы


  • Например добавили Quad это будем Землей для других наших примитивов.
  • У каждого объекта Unity есть обязательный компонент Transform, который отображает значения об Позиции объекта в сцене, его вращении и масштаб.

В окне Inspector отображаются компоненты

Нужно расположить этот квадрат горизонтально и растянуть его. Укажем позицию на начало координат глобальной сцены (0;0;0), угол поворота по X 90 градусов, и увеличим масштаб каждой стороны на 5 метров


  • Добавим кубик на сцену и воспользуемся инструментами для его трансформации, которые находятся в левом углу сцены.




Добавьте ещё 3 объекта

В этом уроке мы разберем инструменты манипуляции объектами в Unity (Move, Rotate, Scale, Rect), работу с компонентом Transform и горячие клавиши для быстрой работы.

1. Создание объектов для тренировки

Прежде чем начать, создайте несколько примитивов для практики:

  • Меню: GameObject -> 3D Object -> Cube (или Cylinder, Sphere).
  • Упражнение: Попробуйте составить из куба, шара и цилиндра пирамидку.
    • Важно: В 3D пространстве объекты могут казаться стоящими друг на друге, но на самом деле висеть в воздухе далеко друг от друга. Всегда вращайте камеру (Alt + мышь) во время перемещения, чтобы контролировать положение со всех сторон

В Unity 6 настройки привязки (Snap) и переключатели Pivot/Global находятся в плавающих панелях (Overlays) прямо внутри окна сцены. Нажмите ` (тильду), если нужно их настроить или вернуть.

2. Инструмент Move Tool (Перемещение)

Отвечает за изменение позиции объекта.

  • Активация: Кнопка на панели инструментов или клавиша W.
  • Гизмо (Стрелки):
    • Тяните за стрелки, чтобы двигать объект строго по одной оси.
    • Тяните за цветные квадратики (между стрелками), чтобы двигать объект сразу в плоскости (по двум осям одновременно).
  • Оси и Цвета:
    • В Unity используется система RGB = XYZ:
      • 🔴 Red (Красный) = X
      • 🟢 Green (Зеленый) = Y (Вверх/Вниз)
      • 🔵 Blue (Синий) = Z.
    • Совет: Запомните, что Y — это всегда высота (вверх), а X и Z — плоскость пола.
  • Точное перемещение (Snapping):
    • Удерживайте Ctrl при перемещении. Объект будет двигаться рывками (привязка к сетке).
    • По умолчанию шаг равен 1 метр (Можно поменять на 0.25 для лучшей точности)
    • Настройка: Изменить шаг можно в меню привязок (иконка магнита/сетки -> Edit Grid and Snap Settings).

3. Компонент Transform (Инспектор)

Каждый объект на сцене обязательно имеет компонент Transform. Он хранит данные о позиции, вращении и масштабе.

  • Position: Можно вводить точные цифры.
    • 0, 0, 0 — центр мировых координат.
    • Чтобы создать плоский пол, можно задать позицию Y = -0.1 (если толщина пола 0.2), чтобы поверхность была ровно на уровне нуля.

4. Инструмент Rotate Tool (Вращение)

Отвечает за поворот объекта.

  • Активация: Клавиша E.
  • Гизмо (Сферы):
    • Тяните за цветные кольца для вращения вокруг конкретной оси.
    • Если тянуть внутри сферы (не за кольца), вращение будет свободным по всем осям сразу (хаотично).
  • Точное вращение:
    • Удерживайте Ctrl! Это позволяет вращать объект строго на фиксированные углы (15, 30, 45, 90 градусов).
    • Это критически важно для ровной стыковки стен, поворотов на 90 или 180 градусов.
  • Euler Angles: В инспекторе вращение задается тремя числами (Углы Эйлера). Чтобы сбросить вращение, введите 0, 0, 0.

5. Инструмент Scale Tool (Масштаб)

Отвечает за размер объекта.

  • Активация: Клавиша R.
  • Гизмо (Кубики на концах):
    • Тяните за центральный кубик для пропорционального увеличения (объект растет равномерно).
    • Тяните за цветные оси для растягивания/сплющивания по одной стороне.
  • Важные нюансы:
    • Сброс масштаба: Стандартный масштаб — это 1, 1, 1. Если ввести 0, 0, 0, объект исчезнет (превратится в точку).
    • Отражение (Mirror): Если ввести -1 в одну из осей масштаба, объект зеркально отразится.
    • Привязка: С зажатым Ctrl масштаб меняется с шагом (например, ровно в 2 раза).

6. Инструмент Rect Tool

Полезный инструмент для 2D интерфейсов и быстрой верстки уровней.

  • Активация: Клавиша T.
  • Отличие от Scale:
    • Scale увеличивает объект от центра (в обе стороны).
    • Rect Tool позволяет тянуть за край или угол объекта. Противоположный край остается на месте.
    • Применение: Удобно подгонять высоту колонн или ширину стен, не сдвигая их основание

7. Сводная таблица горячих клавиш

Эти клавиши идут подряд на клавиатуре (QWERTY), что позволяет держать руку в одном месте.

Клавиша Инструмент Описание
Q Hand / View (Из прошлого урока) Навигация
W Move Перемещение
E Rotate Вращение
R Scale Масштабирование
T Rect Tool Изменение размера за края
Y Transform (Перемещение + Вращение + Масштаб).
