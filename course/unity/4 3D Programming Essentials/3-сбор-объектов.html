3 - Сбор объектов

1. Обзор


В предыдущем уроке вы написали вашу первую строку кода, чтобы вращать собираемый объект в сцене. В этом уроке вы завершите интерактивную сцену гостиной с помощью дополнительного кода, который позволит игроку подбирать собираемый объект, награждая его приятным визуальным эффектом. Вы также добавите больше собираемых объектов по всей комнате, чтобы завершить сцену.

Когда будете готовы начать, перейдите к следующему шагу.

2. Позволить игроку проходить через собираемый объект


Сейчас собираемый объект похож на неподвижный камень — он не сдвинется, когда игрок сталкивается с ним на полной скорости, и даже сбивает игрока с его курса! Нужно настроить собираемый объект так, чтобы игрок мог проходить через него без видимого физического столкновения или толчка.

Это можно сделать с помощью свойства Is Trigger﻿ компонента Collider. Когда вы говорите компоненту коллайдера действовать как триггер вместо физического коллайдера, он больше не будет иметь твёрдого барьера, но всё равно сможет обнаруживать вхождение игрока или других GameObjects.

Триггерный коллайдер﻿ заставляет объект вести себя скорее как облако. Несмотря на то, что он выглядит как твёрдый, самолёт всё равно может пролететь сквозь него, и пилот знает, когда он это сделал.

Инструкции:

  1. Убедитесь, что собираемый объект расположен в вашей сцене так, чтобы игрок мог в него врезаться.
  2. Войдите в режим воспроизведения и попытайтесь столкнуться с собираемым объектом — обратите внимание, что происходит. Выйдите из режима воспроизведения после теста.
  3. Выберите собираемый объект, затем найдите его компонент Collider.
  4. В компоненте Collider включите свойство Is Trigger﻿. Это преобразует физический коллайдер в триггерную область.
  5. Войдите снова в режим воспроизведения, чтобы протестировать. Убедитесь, что игрок может проходить через собираемый объект без какого-либо физического сопротивления.

Собираемый объект всё ещё не исчезает, когда игрок проходит через него. Вы поработаете над этим в следующем шаге.

Не забывайте выходить из режима воспроизведения после тестирования!

3. Добавить функцию OnTriggerEnter

На этом шаге вы напишете код для обнаружения контакта игрока с собираемым объектом.

Вы сделаете это в вашем скрипте, используя функцию OnTriggerEnter﻿, специальную функцию Unity, которая вызывается, когда один объект входит в триггерную зону коллайдера другого объекта.

Важно отметить, что OnTriggerEnter﻿ вызывается только если хотя бы один из объектов имеет компонент Rigidbody. У объекта игрока уже есть компонент Rigidbody, так что всё готово!

Инструкции:

  1. Откройте скрипт Collectible в вашем редакторе кода.
  2. После завершающей фигурной скобки метода Update, но перед последней фигурной скобкой всего скрипта, создайте несколько пустых строк нажатием клавиши Enter (macOS: Return) несколько раз.
  3. Начните вводить «OnTriggerEnter». Если ваша среда разработки поддерживает функцию автозаполнения, вы увидите подсказки.
  4. Выберите или завершите метод OnTriggerEnter в своем скрипте.

Пример:

private void OnTriggerEnter(Collider other) {  

}

Любой код внутри этих фигурных скобок будет выполняться, когда объект с компонентом Rigidbody столкнётся с собираемым объектом. В данном случае нужно заставить объект исчезнуть, что вы сделаете далее.

4. Написать комментарий

Комментарии — это строки в коде, которые не выполняются, служащие заметками или пояснениями. Они важны для поддержания понятного кода, особенно при работе над сложными проектами или в команде.

Здесь вы используете комментарии как pseudo code﻿, практику, когда вы описываете логику кода простым языком до написания функционального кода.

В C# комментарии начинаются с «//», и всё, что идёт после этих двух слэшей на той же строке, игнорируется при исполнении кода.

Инструкции:

  1. В вашем скрипте перейдите к методу OnTriggerEnter, где будете добавлять код, затем нажмите Enter (macOS: Return) несколько раз после открывающей фигурной скобки, чтобы добавить пространство.
  2. Напишите комментарий «Destroy the collectible», так как именно это вы хотите сделать, когда игрок войдёт в его триггерную зону.

Пример:

private void OnTriggerEnter(Collider other) {  
    // Destroy the collectible  
}

5. Уничтожить собираемый объект

На этом шаге вы заставите собираемый объект исчезать, когда игрок будет с ним взаимодействовать. Вы используете метод Destroy﻿ в Unity, который удаляет GameObject из сцены, создавая иллюзию, что игрок собрал объект.

Инструкции:

  1. В методе OnTriggerEnter нажмите Enter (macOS: Return), чтобы добавить новую строку под вашим комментарием.
  2. Введите команду:
Destroy(gameObject);

где «gameObject» — это объект, к которому прикреплен скрипт (ваш собираемый объект).
3. Сохраните скрипт, вернитесь в Unity и войдите в режим воспроизведения.

Вы увидите, что когда игрок сталкивается с собираемым объектом, он исчезает из сцены и из окна Hierarchy, имитируя сбор.

6. Исследовать варианты частиц

Вы, вероятно, заметили, что сбор объекта не был очень удовлетворительным или очевидным; едва ли было видно, что его собрали!

Когда игрок достигает чего-то, ему должен предоставляться визуальный отклик. Простые визуальные эффекты (VFX﻿) — такие как клубы дыма или маленькие взрывы — эффективно предоставляют этот отклик.

В Unity можно использовать системы частиц для имитации сложных визуальных эффектов, таких как огонь, дым или искры. В этом шаге вы выберете систему частиц для визуального отклика вашего собираемого объекта.

Инструкции:

  1. В окне Project перейдите в папку _Unity Essentials > Prefabs > VFX.
  2. Дважды кликните по 3D префабам системы частиц, чтоб просмотреть их.
  3. Выберите подходящий эффект, который хотите использовать.
  4. Выйдите из режима редактирования префабов.

7. Создать и назначить новую переменную для частицы

Переменные хранят данные, которыми можно управлять в коде, например скорость вращения или объекты GameObject.

На этом шаге вы создадите переменную типа GameObject для ссылки на ваш выбранный префаб эффекта частицы, чтобы потом создавать частицы при сборе объекта.

Инструкции:

  1. Откройте скрипт Collectible.
  2. Ниже вашей переменной speed добавьте строку:
public GameObject onCollectEffect;
  1. Сохраните скрипт и перейдите в Unity.
  2. Выберите объект собираемого объекта в сцене.
  3. В инспекторе у переменной On Collect Effect назначьте ваш префаб частицы путем перетаскивания из окна проекта.

8. Создать эффект частицы

Создание экземпляра объекта (Instantiate﻿) — это создание копии префаба во время работы игры.

Инструкции:

  1. В методе OnTriggerEnter добавьте после Destroy код:
// instantiate the particle effect
Instantiate(onCollectEffect, transform.position, transform.rotation);
  1. Сохраните скрипт, войдите в режим воспроизведения.
    Теперь при сборе объекта будет появляться выбранный визуальный эффект.

9. Создайте интересный путь собираемых объектов

Инструкции по созданию ряда объектов:

  • Используйте глобальные координаты в Scene, чтобы объекты были выровнены вдоль прямой линии.
  • В окне Hierarchy выберите комнату, переключитесь на вид сверху.
  • Выделите собираемый объект, нажмите Ctrl+D (Cmd+D) для дублирования.
  • Переместите дубликат по нужной оси, удерживая Ctrl (Cmd) для привязки.
  • Повторите, чтобы создать путь из собираемых объектов.
  • Запустите игру, чтобы проверить игровой процесс.

10. Ограничьте столкновения только для игрока

Проблема: собираемые объекты исчезают при столкновении с мебелью.

Решение: изменить логику так, чтобы сбор происходил только при столкновении с объектом, у которого тег Player.

Инструкции:

  1. Выберите объект игрока, назначьте тег Player в инспекторе.
  2. В скрипте Collectible добавьте if-условие:
if (other.CompareTag("Player")) {
    // код уничтожения и спауна эффекта
}
  1. Переместите вызовы Destroy и Instantiate внутрь этого условия.
  2. Сохраните скрипт и протестируйте в режиме воспроизведения.

11. Очистите окно Hierarchy

Когда много объектов, иерархия становится загромождённой.

Инструкции:

  1. Выделите все собираемые объекты (первый, потом Shift + последний).
  2. Правый клик — Create Empty Parent.
  3. Переименуйте новый пустой объект, например, "Collectibles".

Теперь вы можете сворачивать и разворачивать этот родительский объект для удобства.
