4 - Мини-Практика

1. Лёгкий: Добавьте возможность прыжка

Способность игрового персонажа прыгать открывает безграничные дополнительные геймплейные возможности и механики.

В этом дополнительном задании вы дадите игроку возможность прыгать с помощью всего нескольких строк кода.

Это необязательное задание имеет лёгкий уровень сложности.

Инструкции

  1. Откройте скрипт PlayerController в вашем редакторе кода.

  2. Добавьте следующее объявление переменной в верхней части вашего скрипта, сразу под вашими другими переменными speed и rotationSpeed:

    public float jumpForce = 5.0f;

    После сохранения скрипта эта переменная будет видна и доступна для редактирования в компоненте Player Controller в инспекторе Unity.

  3. Между открывающей и закрывающей фигурными скобками пустой функции Update() добавьте следующий код:

    if (Input.GetButtonDown("Jump")) {
    rb.AddForce(Vector3.up * jumpForce, ForceMode.VelocityChange);
}

    Вот что означает этот код:

    • if (Input.GetButtonDown("Jump")): Проверяет, была ли нажата кнопка Jump в текущем кадре. Действие Jump настраивается в менеджере ввода Unity (Input Manager) и по умолчанию соответствует клавише «Пробел».
    • rb: Это ссылка на компонент Rigidbody игрового объекта, которая используется для применения физических сил.
    • rb.AddForce(Vector3.up * jumpForce, ForceMode.VelocityChange): Применяет к Rigidbody силу, направленную вверх, чтобы объект подпрыгнул.
      • Vector3.up указывает направление вверх Vector(0, 1, 0)
      • jumpForce задает величину силы прыжка.
      • ForceMode.VelocityChange - это режим приложения силы, который напрямую изменяет скорость объекта, делая прыжок мгновенным и независимым от массы объекта.

  4. Сохраните скрипт и вернитесь в Unity. Войдите в режим воспроизведения (Play mode) и нажмите «Пробел», чтобы протестировать новый прыжок. Настройте переменную Jump Force в инспекторе так, как считаете нужным.

2. Средний: Сделайте так, чтобы дверь открывалась при приближении игрока

В настоящее время игрок заперт в гостиной. Если бы он мог открывать двери и входить в другие комнаты, это открыло бы множество новых возможностей. Вы могли бы даже соединить гостиную с кухней и детской комнатой, позволив игроку исследовать все три окружения!

Чтобы игрок мог открыть дверь, вам понадобится добавить новый скрипт, использующий систему анимации Unity — Animator. Возможно, вы этого не осознавали, но вы можете создавать анимации прямо в Unity, а затем запускать их с помощью скриптов.

На игровом объекте (GameObject﻿) Door уже есть компонент Animator с прикрепленной к нему анимацией Door_Open. Вам нужно добавить скрипт, который будет сообщать этой анимации о необходимости запуска, когда игрок входит в триггерную зону двери.

Это необязательное задание имеет средний уровень сложности.

Инструкции

  1. Создайте новый скрипт в папке Unity Essentials > Scripts с именем DoorOpener
    Важно: Имя этого скрипта должно в точности совпадать с именем, объявленным в верхней части класса в приведенном ниже фрагменте кода (DoorOpener).
  2. В окне Scene (Сцена) выберите дверь с правой стороны гостиной, затем в окне Hierarchy (Иерархия) убедитесь, что вы выбрали родительский игровой объект Door, а не дочерние объекты DoorPanel или DoorHandle.
    Родительский GameObject — это тот, к которому прикреплен компонент Animator.
  3. Выбрав GameObject Door, нажмите Add Component (Добавить компонент), затем найдите и добавьте ваш новый скрипт DoorOpener.
  4. Откройте скрипт DoorOpener в вашем редакторе кода, удалите весь стандартный код и замените его, скопировав и вставив код, приведенный ниже.
    Не стесняйтесь прочитать код, чтобы попытаться понять его с помощью комментариев. Когда закончите, сохраните скрипт и вернитесь в редактор Unity.
    Работа скрипта основана на наличии у двери триггерной зоны, которая обнаруживает, когда игрок в нее вошел.
  5. Все еще выбрав GameObject Door, добавьте новый компонент Box Collider, а затем активируйте его свойство Is Trigger.
  6. В компоненте Box Collider нажмите Edit Collider (Редактировать коллайдер), затем используйте элементы управления коллайдером в окне Scene (Сцена), чтобы настроить размер и положение триггерной зоны.
  7. Войдите в режим воспроизведения (Play mode﻿), чтобы протестировать игру.
    Когда игрок войдет в триггерную зону, дверь должна открыться!
using UnityEngine;

public class DoorOpener : MonoBehaviour
{
   private Animator doorAnimator;

   void Start()
   {
       // Получаем компонент Animator, прикрепленный к тому же GameObject, что и этот скрипт
       doorAnimator = GetComponent<Animator>();
   }

   private void OnTriggerEnter(Collider other)
   {
       // Проверяем, вошел ли в триггер игрок (или другой указанный объект)
       if (other.CompareTag("Player")) // Убедитесь, что у GameObject'а игрока установлен тег "Player"
       {
           if (doorAnimator != null)
           {
               // Активируем триггер "Door_Open" в аниматоре
               doorAnimator.SetTrigger("Door_Open");
           }
       }
   }
}

3. Экспертный: Используйте генеративный ИИ для симуляции восхода и заката

Вы будете поражены, как многого можно достичь с помощью больших языковых моделей (large language models, LLMs﻿) генеративного ИИ, таких как Unity Muse, ChatGPT﻿ или Claude﻿. Эти инструменты особенно полезны для создания относительно простого кода. Unity Muse﻿ обучен и усовершенствован для решения специфических задач Unity, поэтому, скорее всего, он предоставит наиболее надежные результаты, но другие LLM﻿ также справятся очень хорошо.

В этом задании экспертного уровня вы используете один из этих инструментов для создания скрипта, который будет медленно вращать направленный свет (Directional Light﻿), симулируя цикл смены дня и ночи в вашей сцене.

Это необязательное задание имеет экспертный уровень сложности.

Инструкции

  1. Перейдите к выбранному вами инструменту генеративного ИИ и введите запрос (промпт), похожий на приведенный ниже:

    «Создай скрипт для Unity, который я могу добавить к моему направленному свету (Directional Light﻿), чтобы он медленно вращался, симулируя течение дня. Количество реальных секунд для прохождения одного дня должно быть переменной, редактируемой в окне Инспектора (Inspector﻿).»

  2. В сгенерированном скрипте найдите строку объявления класса в верхней части скрипта, которая гласит: public class [SCRIPT_NAME] : MonoBehaviour.

    [SCRIPT_NAME] — это то имя, которое вам нужно будет дать вашему скрипту. Имя, сгенерированное для вас, скорее всего, будет отличаться от имени скрипта в примере!

  3. В окне Проекта (Project﻿) создайте новый скрипт, дайте ему соответствующее имя, а затем примените его к игровому объекту (GameObject﻿) Directional Light в вашей сцене.

    Важно: Имя вашего скрипта в окне Проекта и имя, объявленное внутри скрипта в строке объявления класса (public class [SCRIPT_NAME]), должны в точности совпадать! В противном случае в консоли вашего проекта отобразится ошибка.

  4. Откройте скрипт и замените стандартный код на код, сгенерированный ИИ. Сохраните скрипт и вернитесь в редактор (Editor﻿).

  5. В окне Инспектора (Inspector﻿) должна появиться новая переменная, которая позволит вам контролировать время, за которое проходит полный день. В целях тестирования сделайте так, чтобы день проходил быстро.

  6. Войдите в режим воспроизведения (Play mode﻿), чтобы проверить новую функциональность вращения солнца.

    Если что-то не сработает, объясните, что происходит, инструменту ИИ и посмотрите, сможет ли он помочь устранить неполадку
