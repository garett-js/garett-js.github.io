1 - Скрипт Движения

1 Открытие сцены программирования

Первым шагом будет открытие новой сцены для этой миссии — это простая обстановка гостиной.

Инструкция:

  1. В окне Project перейдите в _Unity_Essentials > Scenes_.
  2. Найдите 4_LivingRoom_Programming_Scene и откройте её двойным щелчком.
  3. Отрегулируйте вид 3D-сцены, чтобы хорошо видеть планировку гостиной.

2 Добавление игрока на сцену

Следующий шаг — добавить игрока в сцену. Игрок — это персонаж, которым будет управлять пользователь вашей игры.

В этой сцене в гостиной вашим игроком могут быть:

  • робот-пылесос, собирающий мусор
  • игрушечная машинка, собирающая звёзды
  • заводная мышь, ищущая сыр
  • инопланетянин на НЛО, собирающий драгоценные камни

Выберите тот вариант, который кажется вам наиболее интересным!

Инструкция:

  1. В окне Project перейдите в Unity Essentials > Prefabs > Characters и просмотрите предложенные варианты.
  2. Перетащите выбранного персонажа в сцену, разместив его рядом с главной дверью слева.
    • Внимание: Не двойной клик по префабу в окне Project, иначе откроется режим редактирования префаба. Просто перетащите его в сцену.
  3. При необходимости поверните игрока на 90° по оси Y, чтобы он смотрел в центр комнаты.
  4. В окне Hierarchy переименуйте выбранного персонажа в “Player” для удобства.

3 Создание нового скрипта PlayerController

Пора создать свой первый скрипт на C#!

C# (читается как «си-шарп») — универсальный язык программирования, который широко используется для создания различных приложений, особенно в Unity для написания игровых скриптов.

Первый скрипт будет называться “PlayerController”. В нём вы опишете поведение игрока в игровом мире.

Инструкция:

  1. В окне Project перейдите в Unity Essentials > Scripts. Внутри папки Scripts уже есть папка Provided Scripts — пока её игнорируйте.
  2. Щёлкните правой кнопкой мыши на пустом месте в папке Scripts и выберите Create > MonoBehaviour Script.
  3. Как только появится поле для имени скрипта, сразу переименуйте новый скрипт в "PlayerController" (с заглавными P и C).
    • Важно: Сразу укажите правильное имя — переименование позже может вызвать проблемы.
  4. Нажмите Enter для сохранения имени скрипта.

После этого в Inspector откроется код нового пустого скрипта. Обратите внимание, что имя файла встречается в коде, поэтому орфография критична.

  • Примечание: Если случайно ошиблись в имени или пришлось переименовать, лучше удалить скрипт и создать его заново.

4 Применение скрипта к объекту Player

Теперь приложим скрипт к объекту игрока.

В Unity скрипты на C# — это компоненты, как и Rigidbody или Audio Source, которыми вы уже пользовались. Главное отличие — ваши компоненты можно редактировать.

Инструкция:

  1. В окне Project найдите созданный скрипт PlayerController в папке Scripts.
  2. Перетащите этот скрипт на вашего персонажа игрока в режиме Scene.
    • Не появится видимых изменений сразу. Всё сработало!
  3. В Hierarchy выберите объект игрока и убедитесь, что компонент скрипта появился в нижней части окна Inspector.
  • Примечание: Не забудьте сохранить сцену через Ctrl+S (Cmd+S на macOS).

5 Открытие скрипта PlayerController в редакторе

Unity не позволяет редактировать код непосредственно внутри редактора, поэтому следующий шаг — открыть скрипт PlayerController во внешнем редакторе.

Чаще всего вместе с Unity устанавливается Visual Studio — это IDE (integrated development environment) для написания кода.

Инструкция:

  1. Найдите скрипт PlayerController в окне Project.
  2. Двойной щелчок по файлу откроет его в редакторе по умолчанию (например, Visual Studio).
    • Впервые запуск может занять некоторое время.
  3. Когда IDE откроется, увидите шаблонный код нового скрипта.
  • Примечание: Не волнуйтесь, если IDE выглядит иначе, чем в видеоуроке.
  • Если скрипт не открывается — воспользуйтесь инструкцией по установке Visual Studio и настройте Unity для работы с ним (см. learn.unity.com).

6 Копирование кода и сохранение

В этом шаге мы «оживим» персонажа, вставив готовый код в скрипт PlayerController — он отвечает за движение игрока.

Инструкция:

  1. В редакторе откройте файл PlayerController.cs, выделите всё содержимое (Ctrl+A или Cmd+A) и удалите.
  2. Скопируйте приведённый ниже код (Ctrl+C/Cmd+C), вставьте в файл (Ctrl+V/Cmd+V).
  3. Сохраните изменения (Ctrl+S/Cmd+S).

Если есть ошибки (красные подчеркивания), проверьте написание имени файла PlayerController.

  1. В Unity перейдите в режим Play (игры).
  2. Управляйте игроком с помощью стрелок или клавиш WASD.

Если персонаж не двигается, выйдите из режима Play, перепроверьте и перепроверьте свой скрипт PlayerController. Если ошибки останутся — повторите процедуру вставки кода и сохранения.

  • Если хотите, прочтите комментарии в коде: строки, начинающиеся с //, объясняют работу программы.

Код движения игрока:

using UnityEngine;

// Управляет движением и вращением игрока.
public class PlayerController : MonoBehaviour
{
    public float speed = 5.0f; // Скорость движения игрока.
    public float rotationSpeed = 120.0f; // Скорость вращения игрока.

    private Rigidbody rb; // Ссылка на Rigidbody игрока.

    // Метод Start вызывается один раз в начале.
    private void Start()
    {
        rb = GetComponent<Rigidbody>(); // Получаем компонент Rigidbody.
    }

    // Метод Update вызывается каждый кадр.
    void Update()
    {
        
    }

    // Обработка движения и вращения на физическом уровне.
    private void FixedUpdate()
    {
        // Движение игрока по вертикали.
        float moveVertical = Input.GetAxis("Vertical");
        Vector3 movement = transform.forward * moveVertical * speed * Time.fixedDeltaTime;
        rb.MovePosition(rb.position + movement);

        // Вращение игрока по горизонтали.
        float turn = Input.GetAxis("Horizontal") * rotationSpeed * Time.fixedDeltaTime;
        Quaternion turnRotation = Quaternion.Euler(0f, turn, 0f);
        rb.MoveRotation(rb.rotation * turnRotation);
    }
}

7 Сделайте камеру дочерним объектом игрока

Пока камера неподвижна, и управление игроком кажется отстранённым. Сейчас настроим камеру так, чтобы она следовала за игроком в виде от третьего лица.

Если сделать камеру дочерним объектом игрока (через окно Hierarchy), она будет повторять его положение и вращение — и вы всегда увидите игрока в обзоре камеры.

Инструкция:

  1. Найдите объект Main Camera в окне Hierarchy.
  2. Перетащите Main Camera на объект Player — она станет его дочерним объектом (будет сдвинута вправо).
  3. В компоненте Transform у Main Camera сбросьте значения позиции и вращения на 0.
    • Совет: Быстро сбросить значения можно через контекстное меню (три точки) в правом верхнем углу Transform.
  4. Теперь камера находится точно там же, что и игрок. В режиме Scene скорректируйте её положение выше и чуть назад (чтобы игрок всегда был в кадре). Используйте Preview для проверки.
    • Если камера ушла за левую стену, подвиньте игрока ближе к центру комнаты.
  5. Перейдите в режим Play и проверьте управление — теперь игровое ощущение будет лучше!

8 Редактирование свойств игрока в режиме Play

Правка свойств игрока прямо в режиме Play — быстрый и наглядный способ настроить его параметры.

  • Важно! Любые изменения, внесённые в Play-режиме, временные. Чтобы они сохранились, повторите настройку после выхода и сохраните сцену.

Инструкция:

  1. Включите Play режим, выберите игрока в Hierarchy.
  2. В Inspector появятся новые поля Speed и Rotation Speed (от вашего скрипта PlayerController).
  3. Меняйте значения этих параметров в Inspector, наблюдая за движением персонажа.
    • Например, уменьшите скорость для более медленного движения.
    • Внимание: После редактирования игрок может "замерзнуть". Просто щёлкните в окне Game для продолжения.
  4. Запомните понравившиеся значения, выйдите из Play-режима.
  5. Задайте сохранённые значения Speed и Rotation Speed вне Play-режима и сохраните сцену.
