5 - 3D Мини-Практика

1. Легко: Постройте идеальную башню из блоков с помощью привязки по вершинам

Это дополнительное задание относится к лёгкой сложности. Если хотите пройти — читайте далее, если нет — переходите к следующему этапу.

Вершина (vertex, мн. ч.: vertices) — это точка пересечения граней фигуры, например угол. В Unity функция vertex snapping позволяет идеально выровнять вершины разных GameObject, «прищелкивая» их друг к другу.

Сначала привязка по вершинам немного сложна, поэтому это необязательное задание. Но если овладеете приёмом — он пригодится!

Инструкция

  1. Добавьте новый префаб Block на пол, затем перетащите ещё два блока рядом.
  2. Удерживая клавишу V, левой кнопкой мыши кликните по одной из нижних вершин блока, который хотите поставить сверху.
  3. Перетащите курсор к нужной вершине другого блока — вершины автоматически совместятся.
  4. Повторите процесс, чтобы выстроить идеально ровную башню 3-4 блока в высоту.

2. Средне: Добавьте префабы блоков разных форм

Вы создали интересную башню из прямоугольников, но стало бы круче, если добавить формы — цилиндры, конусы, призмы.

Инструкция

  1. В окне Project откройте _Unity Essentials > Prefabs > Shapes.
  2. Перетащите выбранную форму на сцену.
  3. Чтобы форма обнаруживала столкновения, добавьте компонент Mesh collider и включите свойство Convex.
  4. Чтобы реагировать на силы, добавьте компонент Rigidbody.
  5. Чтобы добавить цвет новому блоку — создайте новый материал и примените его, либо выберите существующий в Mesh Renderer с помощью object picker.
  6. Разместите фигуру в интересной позиции вашей башни.

Совет: Вероятно, потребуется пропорционально масштабировать фигуры. Для этого используйте серую центральную ручку инструмента Scale или значок цепочки в Transform > Scale для связанного масштабирования.

Повторите шаги для других блоков, чтобы сделать сцену интереснее.

3. Эксперт: Добавьте и оформите индивидуальную картину

Комната пока выглядит скучно — добавить свою картину оживит её и сделает индивидуальной.

Чтобы сделать это: создайте пустой холст на сцене с помощью quad, импортируйте изображение, примените его как материал на quad и красиво оформьте рамкой.

Инструкция

  1. В окне Hierarchy ПКМ — выберите 3D Object > Quad, чтобы создать плоскую одностороннюю поверхность.
  2. В компоненте Transform у quad задайте Y rotation — 90 (или другое кратное 90), чтобы холст лежал у стены, после чего разместите quad у нужной стены инструментом Move.
  3. Найдите или подготовьте изображение для вашей картины.
  4. Создайте в папке My Materials новый материал Art_Mat и примените его к quad-объекту.
  5. Для импорта изображения в проект перетащите файл из проводника/файлового менеджера в My Materials в Project. Unity скопирует файл внутрь проекта.
  6. В Inspector Art_Mat, находясь в разделе Surface Inputs — в свойстве Base Map выберите изображение через object picker (⊙).
  7. Подстройте масштаб quad в случае искажения изображения. Обычно нужно растянуть холст, чтобы картинка была шире.
  8. Дублируйте quad (Ctrl+D), переименуйте дубликат во Frame, и сделайте его дочерним объектом для quad.
  9. Отмасштабируйте Frame до 1.1 по всем осям, чтобы слегка увеличить относительно холста, и переместите его за исходный quad, чтобы не перекрывать картину.
  10. Создайте новый материал для рамки, назовите его по желаемому цвету, задайте Base Map красивым цветом, примените его к Frame — получится оформление.

Если хотите — создайте ещё несколько картин аналогично!
