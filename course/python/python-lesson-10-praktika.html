Практические задания - Урок 10: Строки

Инструкция: Решите все задания по порядку. Создайте отдельный файл .py для каждой задачи или решите все в одном файле, разделяя задачи комментариями.

Задача № 1: Перевернуть строку

Уровень сложности: ⭐

Создайте программу, которая печатает строку в обратном порядке.

Примерный вывод
Привет → тевирП

Задача № 2: Палиндром

Уровень сложности: ⭐⭐

Создайте программу, которая проверяет, является ли строка палиндромом. Палиндром — это строка, которая читается одинаково слева направо и справа налево.

Примеры палиндромов:

  • Абоба
  • Лёша на полке клопа нашёл
  • Аргентина манит негра
  • Мир как Рим
Примерный вывод
абоба → абоба это палиндром
привет → тевирп это НЕ палиндром

Задача № 3: Форматирование строки

Уровень сложности: ⭐⭐

Напишите программу, которая форматирует строку так, чтобы каждое слово начиналось с заглавной буквы.

Примерный вывод
Было: "привет я изучаю программирование"
Стало: "Привет Я Изучаю Программирование"

Задача № 4: Замена символов

Уровень сложности: ⭐⭐

Дана строка с названием файла: "Готовый-проект-почти-правки-1-2-финал.psd". Замените все символы - на пробелы. Используйте методы split() и join().

Примерный вывод
Было: "Готовый-проект-почти-правки-1-2-финал.psd"
Стало: "Готовый проект почти правки 1 2 финал.psd"

Задача № 5: Замена гласных

Уровень сложности: ⭐⭐⭐

Напишите программу, которая заменяет все вхождения гласных русских букв в строке на символ *.

Примерный вывод
Было: "привет я изучаю программирование"
Стало: "пр*в*т * *з*ч** пр*гр*мм*р*в*н**"
