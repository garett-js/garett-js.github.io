Урок 15. ООП Часть 1

До настоящего момента мы разрабатывали программы, используя процедурный подход. В рамках данного подхода весь код, включая переменные и функции, размещается в одном файле, без чёткой структурной связи между его компонентами. В результате создаётся монолитная структура, где различные элементы программы хаотично смешаны.

Основные характеристики процедурного подхода:

  • Программа строится с использованием процедур (функций) как ключевых структурных элементов.
  • Данные и функции существуют отдельно друг от друга, без явной привязки.
  • Использование глобальных переменных для хранения данных, повышает риск ошибок: такие переменные доступны для просмотра и изменения любым элементом программы, что затрудняет контроль и отладку, потому что эти переменные может видеть и изменять кто хочет.

Рассмотрим пример программы, написанной в процедурном стиле, чтобы выделить её ограничения и проблемы.

Python
def main():
    player_name = "Геральт из Ривии"
    player_hp = 100
    player_attack = 20
    player_defence = 10

    monster_name = "Леший из Лихолесья"
    monster_hp = 50
    monster_attack = 12
    monster_defence = 8

    def player_deals_damage():
        nonlocal monster_hp
        damage = player_attack - monster_defence
        if damage < 0:
            damage = 0
        monster_hp -= damage

        if monster_hp < 0:
            print("Монстр проиграл")
            return

        print(f"Игрок наносит монстру {damage} урона")
        print(f"У монстра осталось {monster_hp} HP")

    def monster_deals_damage():
        nonlocal player_hp
        damage = monster_attack - player_defence
        if damage < 0:
            damage = 0
        player_hp -= damage
        
        print(f"Монстр наносит игроку {damage} урона")
        print(f"У игрока осталось {player_hp} HP")

    def level_up():
        nonlocal player_hp, player_attack, player_defence
        print("Поздравляем! Уровень повышен! Ваши статы усилены!")
        player_hp += 10
        player_attack += 5
        player_defence += 2

    def show_player_stats():
        print(f"Имя игрока: {player_name}")
        print(f"Здоровье игрока: {player_hp}")
        print(f"Атака игрока: {player_attack}")
        print(f"Защита игрока: {player_defence}")

    def show_monster_stats():
        print(f"Имя монстра: {monster_name}")
        print(f"Здоровье монстра: {monster_hp}")
        print(f"Атака монстра: {monster_attack}")
        print(f"Защита монстра: {monster_defence}")

    # Выпускаем кракена
    player_deals_damage()
    player_deals_damage()
    monster_deals_damage()
    player_deals_damage()
    player_deals_damage()
    player_deals_damage()

    level_up()
    show_player_stats()

if __name__ == "__main__":
    main()

На данном этапе всё кажется упорядоченным, однако попробуем добавить ещё одного монстра, похожего на существующего. Это приведёт к необходимости создавать дополнительные переменные для нового монстра, а также писать отдельные функции, связанные с ним.

Основная проблема заключается в том, что эти переменные и функции не имеют структурной связи друг с другом. Это делает код менее понятным и увеличивает вероятность ошибок.

Например, можно случайно обратиться к переменным, не относящимся к конкретному монстру, что приведёт к некорректной работе программы и непредсказуемым результатам.

А теперь представьте, что монстров в игре может быть несколько десятков, а то и сотни, или же появляется необходимость поддерживать несколько игроков. В таких условиях наш код быстро превратится в хаотичный и неподдающийся управлению массив, полный дублирования и путаницы. Это усложнит не только чтение и поддержку кода, но и внесение изменений или исправление ошибок.

Примечание: Наш код и работа превратиться в настоящий кошмар и пытку!

Как справиться с подобной ситуацией? Решение заключается в использовании другой парадигмы программирования, известной как Объектно-Ориентированное Программирование (ООП). Этот подход помогает структурировать код, связывая данные и функциональность в единые логические блоки.

Давайте сразу преобразуем наш пример в стиле ООП. После этого я подробно объясню, как работает данный подход и какие преимущества он даёт.

  1. Создание класса.
    Первым шагом мы должны создать класс, который станет основой для создания объектов. Класс можно рассматривать как шаблон или трафарет, который определяет общие свойства и действия для всех объектов одного типа.
  2. Назовём класс Character.
    Этот будет абстрактный персонаж. Классы всегда называются с заглавной буквы. Класс создаётся за пределами функции main(), чтобы быть доступным везде в программе.
  3. Добавление свойств и методов.
    Внутри класса мы опишем свойства и методы будущих объектов. Свойства характеризуют объект (например, имя, количество жизней), а методы определяют его действия (например, атака, защита).
  4. Параллель с реальной жизнью.
    Чтобы лучше понять, представьте, что вокруг нас множество объектов: люди, автомобили, здания. У каждого из них есть характеристики (например, возраст, цвет, вес) и действия (учиться, ездить, строиться). В реальности у объектов могут быть миллионы свойств и действий, поэтому для решения задачи важно абстрагироваться — выделить только самые значимые свойства и методы, которые нам необходимы в данном случае.
  5. Добавляем свойства персонажа.
    В данном случае мы определим такие свойства, как имя, количество жизней, сила атаки и уровень защиты. В Python свойства объекта создаются в конструкторе класса.
  6. Создание конструктора класса.
    Для создания объектов нужен конструктор. В Python конструктор - это специальный метод с именем __init__. Этот метод автоматически вызывается при создании объекта. В конструкторе мы перечисляем параметры, которые нужно указать при создании объекта, а затем инициализируем свойства значениями этих параметров.
  7. Ключевое слово self.
    В Python первым параметром любого метода класса должно быть ключевое слово self, которое ссылается на текущий объект. Это необходимо, чтобы чётко указать, что мы обращаемся к свойствам данного объекта, а не к переменным или значениям из внешней области видимости. Проще говоря, self можно перевести как "себя" или "этот" объект. Обращение к самому себе.
  8. Особенности Python в создании свойств.
    В Python свойства объекта создаются динамически при их первом присвоении. Мы присваиваем значения свойствам через self.имя_свойства = значение. Python автоматически создаёт эти свойства для объекта.
  9. Создание объекта.
    Теперь мы можем создать новый объект, используя новый тип данных (название нашего класса) и вызов конструктора. Этот объект будет обладать всеми свойствами и методами, описанными в классе.
Python
def main():
    # Создание экземпляра класса (объекта)
    character = Character("", 1, 1, 1)

    character.hp = 100  # Изменение свойства
    print(character.hp)  # Вывод свойства

if __name__ == "__main__":
    main()

Для создания нового экземпляра класса (новый объект), мы сначала указываем имя класса, затем в круглых скобках передаём параметры конструктора. Python автоматически вызывает метод __init__ и создаёт объект с указанными свойствами.

После этого у нас есть полностью готовый объект со своими уникальными свойствами. Чтобы обратиться к свойствам или методам объекта, используется точечный синтаксис. Например, мы можем узнать текущее значение свойства, вызвать метод объекта, или даже изменить значение свойства.

Гибкость инициализации в Python.

В Python можно создавать свойства объекта не только в конструкторе, но и в любой момент после создания объекта. Также можно задавать значения по умолчанию прямо в параметрах конструктора:

Python
class Character:
    def __init__(self, name="Неизвестный", hp=1, attack=1, defence=1):
        self.name = name
        self.hp = hp
        self.attack = attack
        self.defence = defence
        # Можно добавить дополнительные свойства
        self.level = 1
        self.experience = 0

Создание нескольких объектов

Одно из главных преимуществ ООП — это возможность создавать множество уникальных объектов, используя один и тот же класс как основу.

Класс выступает в роли шаблона, который определяет общую структуру (свойства и методы), а каждый объект, созданный на его основе, может иметь собственные данные и поведение.

Python
def main():
    # Создание экземпляра класса (объекта)
    player = Character("Геральт из Ривии", 100, 20, 10)
    monster1 = Character("Леший из Лихолесья", 50, 12, 8)
    monster2 = Character("Злобный Бобр", 2000, 50, 1)

    print(player.name)    # "Геральт из Ривии"
    print(monster1.name)  # "Леший из Лихолесья"
    print(monster2.name)  # "Злобный Бобр"

if __name__ == "__main__":
    main()

Мы создали три разных объекта, используя единственный шаблон класса Character.

Это наглядно демонстрирует удобство и гибкость объектно-ориентированного программирования.

Уникальные свойства объектов:

Каждый объект — player, monster1, monster2 — обладает одинаковым набором свойств, например, name. Однако самое важное — у каждого из этих объектов значение свойства name уникально. Это позволяет хранить уникальную информацию для каждого объекта и работать с ними независимо.

Связь с self

Когда мы вызываем конструктор класса для создания нового объекта, ключевое слово self внутри класса автоматически связывается с этим объектом. Проще говоря, self обозначает "текущий объект", для которого выполняется код.

Если в конструкторе класса написано:

Python
self.name = name

И создаётся объект player, то это выражение становится:

Python
player.name = name

А если создаётся объект monster1, то оно трансформируется в:

Python
monster1.name = name

Таким образом, self автоматически заменяется текущим объектом, что делает создание и управление объектами простым и логичным.

Добавим методы для вывода информации о персонаже

Создадим метод show_stats, который будет выводить основные характеристики объекта, такие как имя, здоровье, атака и защита.

После создания объекта мы можем вызвать его метод, используя точечный синтаксис. Обязательно ставьте круглые скобки после имени метода, как при вызове обычной функции.

Свойство объекта – вызывается через точку и без скобок
Метод объекта – вызывается через точку и со скобками

Методы позволяют делать объекты более «живыми» и взаимодействующими с данными. Это один из ключевых аспектов работы в стиле ООП.

Важная особенность Python: Все методы класса должны принимать self в качестве первого параметра, даже если они не используют его. Это позволяет методу получить доступ к свойствам и другим методам текущего объекта.

Python

Теперь наш код стал структурированным и логичным, ведь все свойства и методы объекта объединены в одном месте — внутри класса. Такой подход не только делает код аккуратным, но и предотвращает путаницу, поскольку все элементы связаны по смыслу и удобно «упакованы».

Преимущества, которые мы получили:

  1. Связанность данных и функций: Все свойства и методы, относящиеся к одному объекту, находятся внутри его класса, а не разбросаны по коду.
  2. Изоляция данных: Мы чётко определяем, к какому объекту относятся те или иные свойства и методы. Теперь невозможно случайно «перепутать» данные одного персонажа с данными другого.
  3. Легкость масштабирования: Для создания нового объекта достаточно использовать класс, без необходимости копирования кода.

Python
class Character:
    # Конструктор
    def __init__(self, name, hp, attack, defence):
        self.name = name
        self.hp = hp
        self.attack = attack
        self.defence = defence

    # Методы
    def show_stats(self):
        print(f"Имя: {self.name}")
        print(f"Здоровье: {self.hp}")
        print(f"Атака: {self.attack}")
        print(f"Защита: {self.defence}")

    def deal_damage(self, target):
        damage = self.attack - target.defence
        if damage < 0:
            damage = 0
        target.hp -= damage

        if target.hp <= 0:
            print(f"{target.name} проиграл")
        else:
            print(f"{self.name} наносит {target.name} {damage} урона. У {target.name} осталось {target.hp} HP.")

    def level_up(self):
        print(f"Поздравляем, {self.name}! Уровень повышен! Ваши статы усилены!")
        self.hp += 10
        self.attack += 5
        self.defence += 2

def main():
    # Создание экземпляра класса (объекта)
    player = Character("Геральт из Ривии", 100, 20, 10)
    monster1 = Character("Леший из Лихолесья", 50, 12, 8)
    monster2 = Character("Злобный Бобр", 2000, 50, 1)

    # Выпускаем кракена
    player.deal_damage(monster1)
    player.deal_damage(monster1)
    monster1.deal_damage(player)
    player.deal_damage(monster1)
    player.deal_damage(monster1)
    player.deal_damage(monster1)

    player.level_up()
    player.show_stats()

if __name__ == "__main__":
    main()

Аннотации типов в Python

Python поддерживает аннотации типов, которые помогают сделать код более читаемым и позволяют IDE предоставлять лучшие подсказки:

Python
from typing import Optional

class Character:
    def __init__(self, name: str, hp: int, attack: int, defence: int) -> None:
        self.name: str = name
        self.hp: int = hp
        self.attack: int = attack
        self.defence: int = defence

    def show_stats(self) -> None:
        print(f"Имя: {self.name}")
        print(f"Здоровье: {self.hp}")
        print(f"Атака: {self.attack}")
        print(f"Защита: {self.defence}")

    def deal_damage(self, target: 'Character') -> None:
        damage: int = self.attack - target.defence
        if damage < 0:
            damage = 0
        target.hp -= damage

        if target.hp <= 0:
            print(f"{target.name} проиграл")
        else:
            print(f"{self.name} наносит {target.name} {damage} урона. У {target.name} осталось {target.hp} HP.")

    def level_up(self) -> None:
        print(f"Поздравляем, {self.name}! Уровень повышен! Ваши статы усилены!")
        self.hp += 10
        self.attack += 5
        self.defence += 2

Динамическое добавление свойств

В Python можно добавлять новые свойства к объекту даже после его создания:

Python
def main():
    player = Character("Геральт из Ривии", 100, 20, 10)
    
    # Добавляем новое свойство динамически
    player.magic_power = 50
    player.inventory = ["меч", "зелье лечения"]
    
    print(f"Магическая сила: {player.magic_power}")
    print(f"Инвентарь: {player.inventory}")

Строковое представление объекта

В Python можно определить, как объект будет выглядеть при выводе через print() или str():

Python
class Character:
    def __init__(self, name: str, hp: int, attack: int, defence: int) -> None:
        self.name = name
        self.hp = hp
        self.attack = attack
        self.defence = defence

    def __str__(self) -> str:
        return f"{self.name} (HP: {self.hp}, ATK: {self.attack}, DEF: {self.defence})"

    def __repr__(self) -> str:
        return f"Character('{self.name}', {self.hp}, {self.attack}, {self.defence})"

# Использование:
def main():
    player = Character("Геральт из Ривии", 100, 20, 10)
    print(player)  # Выведет: Геральт из Ривии (HP: 100, ATK: 20, DEF: 10)
    print(repr(player))  # Выведет: Character('Геральт из Ривии', 100, 20, 10)

Эти особенности делают Python очень гибким языком для объектно-ориентированного программирования, позволяя писать выразительный и легко читаемый код.
