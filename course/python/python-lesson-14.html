Урок 14: Функции. Часть 2

Функция main и точка входа

Каждая программа на Python может иметь точку входа — функцию main(). Запуск файла начинается с верхней строки скрипта, но принято явно обозначать стартовый участок кода конструкцией:

Python
def main() -> None:
    print("Это точка входа программы")

if __name__ == "__main__":
    main()

__name__ == "__main__" проверяет, запущен ли файл напрямую. При импорте как модуль main() не вызывается автоматически.

Функции как объекты

Python — язык, где всё является объектом, включая функции. Их можно сохранять в переменных, передавать как аргументы и возвращать из других функций.

Python
def print_value(value: int) -> None:
    print(value)

printer = print_value   # присвоили функции переменную
printer(42)             # 42
Python
from typing import Callable

# Аннотируем функцию, принимающую функцию-обработчик
Handler = Callable[[int], None]

def run_twice(handler: Handler, value: int) -> None:
    handler(value)
    handler(value)

run_twice(print_value, 7)  # 7, затем 7

Как передаются аргументы

При вызове функции управление передаётся внутрь неё, затем возвращается в точку вызова. Важно понимать модель: Python использует «передачу ссылок на объекты» (иногда говорят «pass-by-assignment»).

  • Неизменяемые объекты (int, str, float, bool, tuple) — изменить сам объект нельзя, поэтому «кажется», что передаются по значению.
  • Изменяемые объекты (list, dict, set, собственные классы) — передаётся та же ссылка; изменения внутри функции видны снаружи.
Python
def add_one(n: int) -> None:
    n += 1

x = 10
add_one(x)
print(x)  # 10 — x не изменился (int неизменяемый)


def append_item(items: list[int]) -> None:
    items.append(99)

nums = [1, 2, 3]
append_item(nums)
print(nums)  # [1, 2, 3, 99] — список изменился

Чтобы не менять исходную коллекцию внутри функции, делайте копию: items.copy(), срез items[:] или используйте list(items).

Возвращаемые значения

Если функция не содержит return, она возвращает None.

Python
def empty_function():
    pass

print(empty_function())  # None

Чтобы вернуть несколько значений, удобно использовать кортеж (распаковка):

Python
def get_point() -> tuple[int, int]:
    return 12, 2

x, y = get_point()
print(f"Координата x = {x}")
print(f"Координата y = {y}")

Анонимные функции (lambda)

Анонимные (лямбда-) функции не имеют имени и записываются через ключевое слово lambda.

Python
hello = lambda: "Я анонимная функция"
print(hello())

# Практичный пример: сортировка по длине строки
words = ["python", "ai", "development"]
print(sorted(words, key=lambda s: len(s)))

«Стрелочная» запись (однострочные функции)

Если логика функции укладывается в одно выражение, можно использовать lambda или однострочную def:

Python
def get_message(count: int) -> str: return f"У вас {count} сообщений"
print(get_message(5))

get_msg = lambda count: f"У вас {count} сообщений"
print(get_msg(42))

Параметры функций

Функция может иметь обязательные позиционные параметры, необязательные со значением по умолчанию, позиционные-только (/) и ключевые-только (*). Рассмотрим наиболее востребованные варианты.

Именованные (ключевые) параметры

Python
def get_super_value1(*, value1: int = 0, value2: int = 0) -> int:
    """Обе переменные имеют значения по умолчанию"""
    return value1 * value2 - 42

get_super_value1(value2=10)

Параметры после символа * обязательны к передаче по имени.

Python
def get_super_value2(*, value1: int, value2: int) -> int:
    return value1 * value2 - 42

get_super_value2(value1=10, value2=10)

Nullable‑подобное поведение

Python
def get_super_value3(*, value1: int | None = None, value2: int | None = None) -> int:
    value1 = value1 or 0
    value2 = value2 or 0
    return value1 * value2 - 42

get_super_value3(value1=10)

Позиционные параметры со значениями по умолчанию

Python
def hello(name: str, msg: str, age: int = 18) -> str:
    return f"{msg}! Меня зовут {name}! и мне {age}"

print(hello("Маша", "Привет", 20))
print(hello("Роман", "Привет"))

Порядок параметров в сигнатуре: [positional], /, [positional-or-keyword], *, [keyword-only].

Позиционные‑только и ключевые‑только

Python
def f(a, b, /, c, d, *, e, f):
    print(a, b, c, d, e, f)

# f(a=1, b=2, c=3, d=4, e=5, f=6)  # TypeError: a и b — только позиционно
f(1, 2, 3, 4, e=5, f=6)

Область видимости и вложенные функции

Python использует лексическую область видимости (LEGB — Local, Enclosing, Global, Built-ins).

Python
def main() -> None:
    inside_main = True

    def my_function() -> None:
        inside_my_function = True
        print(inside_main)        # доступно из внешней области
        print(inside_my_function) # локальная переменная

    my_function()
    # print(inside_my_function)  # NameError: переменная вне области видимости

main()
Python
counter = 0

def use_global() -> None:
    global counter
    counter += 1

use_global()
print(counter)  # 1

nonlocal — для изменения переменной из замыкающей области; global — из модуля.

Замыкания

Python
def add(num_add: int):
    def inner(i: int) -> int:
        return num_add + i
    return inner

add2 = add(2)
print(add2(3))  # 5
print(add2(4))  # 6
Python
def make_counter(increment: int):
    count = 0
    def counter() -> int:
        nonlocal count
        count += increment
        return count
    return counter

counter1 = make_counter(1)
counter2 = make_counter(2)

print(counter1())  # 1
print(counter1())  # 2
print(counter1())  # 3

print(counter2())  # 2
print(counter2())  # 4

nonlocal позволяет изменять переменную из замыкающей области.

Рекурсия

Рекурсия — это когда функция вызывает саму себя для выполнения задачи.

Рекурсивная функция должна:

  1. Иметь базовый случай для остановки.
  2. При каждом вызове приближаться к базовому случаю.

Пример: сумма элементов списка

Python
def recursive_sum(numbers: list[int]) -> int:
    print(numbers)
    if len(numbers) == 1:
        return numbers[0]          # базовый случай
    return numbers[0] + recursive_sum(numbers[1:])

print(recursive_sum([1, 2, 3, 4, 5, 6, 7, 8, 9]))  # 45

Преимущества: лаконичность при работе с деревьями/графами. Важно учитывать ограничение глубины рекурсии (по умолчанию ~1000 вызовов, можно изменить sys.setrecursionlimit).

Пошаговое выполнение рекурсии

Ниже раскрутка (углубление) и обратный ход (сворачивание) стека вызовов для списка из 9 элементов.

  1. Первый вызов recursive_sum([1, 2, 3, 4, 5, 6, 7, 8, 9])
    • numbers — длиной 9, базовый случай не выполнен.
    • Вычисляется numbers[0] → 1.
    • Рекурсивный вызов с хвостом [2, 3, 4, 5, 6, 7, 8, 9].
  2. Второй вызов recursive_sum([2, 3, 4, 5, 6, 7, 8, 9]) — берём 2, вызываем с хвостом.
  3. Третий вызов recursive_sum([3, 4, 5, 6, 7, 8, 9]) — берём 3, вызываем с хвостом.
  4. … процесс продолжается …
  5. Девятый вызов recursive_sum([9]) — базовый случай, вернуть 9.

Сворачивание стека: 8+9=17 → 7+17=24 → 6+24=30 → 5+30=35 → 4+35=39 → 3+39=42 → 2+42=44 → 1+44=45.

На каждом шаге в стеке хранится текущее numbers[0] и ссылка на следующий подсписок. После получения результата из глубины стек разворачивается, суммируя значения.
