Урок 13. Python Функции. Часть 1

Зачем нужны функции

Создание функции

Функция
Функция — это блок кода, который выполняет определенную задачу и может быть вызван по имени. Функции помогают организовывать код и избегать его повторения.

Преимущества функций

  • Упрощают код.
  • Улучшают читаемость.
  • Позволяют многократно использовать один и тот же блок.
  • Облегчают тестирование и поддержку программы.
Объявление функции

В Python функции объявляются с ключевым словом def, за которым следует имя и список параметров в скобках. После двоеточия пишется тело функции с отступом 4 пробела.

Python
def greet() -> None:
    """Выводит приветствие в консоль."""
    print("Привет!")

Чтобы выполнить код внутри функции, вызовите её по имени:

Python
greet()  # Привет!

Функции с параметрами

Python
def add(a: int, b: int) -> int:
    return a + b

result = add(3, 5)
print(result)  # 8

В Python типы не проверяются во время выполнения, но mypy или другие анализаторы могут проверить аннотации.

«Стрелочная» функция

Для компактных выражений в Python используется lambda либо однострочная запись def.

Python
add_lambda = lambda a, b: a + b
print(add_lambda(2, 3))  # 5

# Однострочная обычная функция
def add_short(a: int, b: int) -> int: return a + b

Важно: lambda в Python ограничена одним выражением — никаких print() / if / for внутри.

Параметры по умолчанию

В Python значения по умолчанию указываются через знак = прямо в списке параметров.

Python
def greet(name: str = "Гость") -> None:
    print(f"Привет, {name}!")

greet()          # Привет, Гость!
greet("Анна")    # Привет, Анна!

Значения по умолчанию вычисляются один раз при определении функции — избегайте изменяемых объектов (list, dict) как дефолтные значения.

Именованные (ключевые) аргументы

Python позволяет передавать аргументы по имени, что делает вызов более читаемым и даёт возможность изменять порядок.

Python
def create_character(name: str, *, race: str = "Human", level: int = 1) -> None:
    print(f"{name} — {race} уровня {level}")

create_character("Геральт", race="Witcher", level=42)
create_character("Лара")

Параметры после * обязательны к передаче по имени.
До * — позиционные либо именованные.
Аналог Dart-овских «именованных обязательных/необязательных» параметров.

Переменное число аргументов (*args, **kwargs)

Python
def sum_all(*numbers: int) -> int:
    return sum(numbers)

print(sum_all(1, 2, 3, 4))  # 10

**kwargs собирает именованные аргументы в словарь.

Возврат нескольких значений

Python
def stats(a: int, b: int):
    return a + b, a * b

s, m = stats(2, 5)
print(s, m)  # 7 10

Практические советы

  1. Докстринги — строки сразу после def, описывающие функцию. Используются IDE и help().
  2. Type Hints — облегчает чтение и статическую проверку (mypy).
  3. PEP 8 отступы — 4 пробела, а не табы.
  4. Не злоупотребляйте глобальными переменными — передавайте данные параметрами.

Используйте аннотации типов и докстринги — это облегчает поддержку кода и позволяет инструментам, таким как mypy, находить ошибки до запуска программы.
