Функции с возвратом значения

Идея

Функция может вернуть значение в место вызова. Возвращённое значение можно присвоить переменной, вывести или использовать в выражении.

  • int() — возвращает целое
  • float() — возвращает вещественное
  • range() — возвращает последовательность
  • abs() — модуль числа
  • len() — длину последовательности

Синтаксис return

Python — Общий вид
def название_функции():
    блок_кода
    return выражение

Выражение после return вычисляется и его значение возвращается вызывающей стороне.

Пример: Фаренгейт → Цельсий

Python — Версия с промежуточной переменной
def convert_to_celsius(temp):
    result = (5 / 9) * (temp - 32)
    return result

temp = float(input('Введите градусы по Фаренгейту: '))
celsius = convert_to_celsius(temp)
print(celsius)
Python — Возврат сразу выражения
def convert_to_celsius(temp):
    return (5 / 9) * (temp - 32)

Несколько return

Python — Конвертация оценки
def convert_grade(grade: int) -> int:
    if grade >= 90:
        return 5
    elif grade >= 80:
        return 4
    elif grade >= 70:
        return 3
    elif grade >= 60:
        return 2
    else:
        return 1

grade = int(input('Введите вашу отметку по 100-балльной системе: '))
print(convert_grade(grade))

Срабатывает только первый достигнутый return. Остальной код в функции не выполняется.

Python — Первый return «побеждает»
def get_grade():
    return 10
    return 20

print(get_grade())  # 10

Если ничего не вернуть

Если функция не возвращает значение явно, возвращается None.

Python — Неявный None
def get_middle_number(a, b, c):
    mx = max(a, b, c)
    mn = min(a, b, c)
    mid = a + b + c - mx - mn

print(get_middle_number(4, 7, 2))  # None

Практика: задачи

Python — Гипотенуза
def compute_hypotenuse(a: float, b: float) -> float:
    return (a ** 2 + b ** 2) ** 0.5

print(compute_hypotenuse(3, 4))
print(compute_hypotenuse(5, 12))
print(compute_hypotenuse(1, 1))

x = int(input())
y = int(input())
print(compute_hypotenuse(x, y))
# В модуле math есть аналог: math.hypot(x, y)
Python — Расстояние между точками
def get_distance(x1: float, y1: float, x2: float, y2: float) -> float:
    return compute_hypotenuse(x1 - x2, y1 - y2)

x1, y1 = float(input()), float(input())
x2, y2 = float(input()), float(input())
print(get_distance(x1, y1, x2, y2))
Python — Сумма цифр
def sum_digits(n: int) -> int:
    result = 0
    while n > 0:
        result += n % 10
        n //= 10
    return result

num = int(input())
print(sum_digits(num))
Python — Среднее по списку
def compute_average(numbers: list[float]) -> float:
    return sum(numbers) / len(numbers)

numbers = [1, 3, 5, 1, 6, 8, 10, 2]
print(compute_average(numbers))  # 4.5

Булевы функции

Функции могут возвращать любые типы, в том числе логические значения.

Python — Проверка чётности
def is_even(number: int) -> bool:
    return number % 2 == 0

n = int(input())
print('Это число чётное.' if is_even(n) else 'Это число нечётное.')
Python — Валидация ввода
def is_invalid(model: int) -> bool:
    return model not in (100, 200, 300)

model = int(input())
while is_invalid(model):
    print('Допустимыми номерами моделей являются 100, 200 и 300.')
    model = int(input())

Несколько возвращаемых значений

Через запятую можно вернуть несколько выражений. Они упакуются в кортеж и могут быть распакованы в переменные.

Python — Возврат трёх степеней
def get_powers(num: int) -> tuple[int, int, int]:
    return num**2, num**3, num**4

a, b, c = get_powers(2)
print(a)
print(b)
print(c)
Python — Несовпадение количества
def foo():
    return 10, 20, 30

a, b = foo()  # ValueError: too many values to unpack (expected 2)
