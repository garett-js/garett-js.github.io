Функции с параметрами

Аннотация

Создание пользовательских функций с параметрами. Аргументы и параметры, влияние изменений параметров внутри функции.

Зачем параметры

В прошлом уроке мы определили draw_box(), печатающую прямоугольник 5×7. Хотим управлять размерами при вызове.

Python — Базовая версия
def draw_box():
    for i in range(5):
        print('*' * 7)

Синтаксис параметров

Функции с параметрами объявляются как и без параметров, но имена параметров указываются в круглых скобках.

Python — Общий вид
def название_функции(параметры):
    блок_кода

Параметризуем draw_box

Передадим высоту и ширину как параметры.

Python — Параметры height и width
def draw_box(height, width):
    for i in range(height):
        print('*' * width)

# 5 × 7
draw_box(5, 7)

# 10 × 15
draw_box(10, 15)

Несколько вызовов

Python — Разные размеры
draw_box(3, 3)
print()
draw_box(5, 5)
print()
draw_box(4, 10)

Аргументы как переменные

Можно передавать не только константы, но и значения переменных.

Python — Передача переменных
n = 3
m = 9
draw_box(n, m)

Ещё примеры

Функции могут принимать сколько угодно параметров. Ниже — два примера.

Python — Печать N раз
def print_hello(n: int) -> None:
    print('Hello' * n)

print_hello(3)
print_hello(5)
times = 2
print_hello(times)
Python — Печать произвольного текста N раз
def print_text(txt: str, n: int) -> None:
    print(txt * n)

print_text('Hello', 5)
print_text('A', 10)

Параметры vs аргументы

Аргумент — данные, которые передаются в функцию при вызове. Параметр — переменная внутри определения функции, которая принимает значение аргумента.

Python — Параметры функции
def draw_box(height, width):
    for i in range(height):
        print('*' * width)

# height и width — параметры
Python — Аргументы вызова
height = 10
draw_box(height, 9)
# height и 9 — аргументы

Изменения параметров внутри функции

Изменение значений параметров внутри функции не влияет на аргументы, переданные при вызове (для неизменяемых типов).

Python — Переопределение параметров
def draw_box(height, width):
    height = 2
    width = 10
    for i in range(height):
        print('*' * width)

n = 5
m = 7
draw_box(n, m)
print(n, m)  # 5 7

Параметры — локальные имена функции. Их изменение не изменяет аргументы снаружи.

Примечания

Важно

  • Функции в Python могут принимать сколько угодно параметров.
  • Термины: «формальные параметры» (в определении) и «фактические параметры» (аргументы вызова).
