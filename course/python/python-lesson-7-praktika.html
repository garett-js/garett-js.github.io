Практические задания - Урок 7: Циклы

Инструкция: Решите все задания по порядку. Создайте отдельный файл .py для каждой задачи или решите все в одном файле, разделяя задачи комментариями.

Задача № 1: Flutter шикарен

Уровень сложности: ⭐

Напишите программу, которая выводит в консоль строку Flutter шикарен 100500 раз.

Задача № 2: Возведение в степень

Уровень сложности: ⭐

Есть переменная value = 10 и переменная exp = 3.
Для каждого из чисел от 0 до value нужно вывести в консоль текст в формате:

Примерный вывод
Число <текущее число> в степени <степень> равно <результат>
...
Число 0 в степени 3 равно 0
Число 1 в степени 3 равно 1
Число 2 в степени 3 равно 8
...

Задача № 3: Четные и нечетные

Уровень сложности: ⭐⭐

1. Нужно вывести в консоль только нечетные числа из диапазона от 1 до 5000.

2. Нужно вывести в консоль сумму всех четных чисел из диапазона от 1 до 5000.

Задача № 4: Звёздный треугольник

Уровень сложности: ⭐⭐

Есть переменная n – катет прямоугольного равнобедренного треугольника.
Напишите программу, которая выводит звёздный треугольник.

Примерный вывод для n = 5
*
**
***
****
*****

Задача № 5: Переворот числа

Уровень сложности: ⭐⭐

Дано целое число. Напишите программу, которая меняет порядок цифр числа на обратный.
Используйте цикл while.

Примерный вывод
Было: 123654987
Стало: 789456321

Задача № 6: Проклятая жила

Уровень сложности: ⭐

Шахтёр добывает руду в шахте, пронумерованной с 1 до 15. Каждая 4-я жила оказалась проклятой и даёт урон, её нужно пропустить. Используйте цикл for и оператор continue, чтобы вывести только безопасные номера жил.

Задача № 7: Сумма кратных

Уровень сложности: ⭐

Найти сумму чисел от 100 до 200 кратных 17.
