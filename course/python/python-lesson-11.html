Словари (Map) в Python

Почему нужен словарь (dict)

Возьмём обычный школьный журнал. Список учеников и их оценки по предметам.
Как связать ученика с его оценками?

Попытка 1 — два списка

Python
students = ['Аня', 'Боря', 'Наташа', 'Глеб', 'Даша']
student_grades = [
    [5, 4, 5],  # Аня
    [3, 5, 4],  # Боря
    [5, 5, 5],  # Наташа
    [4, 3, 4],  # Глеб
    [5, 4, 3],  # Даша
]

student = 'Наташа'

if student in students:
    idx = students.index(student)
    print(f"{student}: {student_grades[idx]}")
else:
    print(f"Ученик {student} не найден.")

Проблемы: линейный поиск O(n) + риск рассинхронизации двух списков.

Попытка 2 — список списков (вложенных)

Python
students = [
    ['Аня', [5, 4, 5]],
    ['Боря', [3, 5, 4]],
    ['Наташа', [5, 5, 5]],
    ['Глеб', [4, 3, 4]],
    ['Даша', [5, 4, 3]],
]
student = 'Наташа'

for name, grades in students:
    if name == student:
        print(f"{student}: {grades}")
        break
else:
    print("Ученик не найден")

Поиск всё ещё O(n). Нужно приведение типов? Нет, но читать и обновлять неудобно.

Решение: dict (словарь)

В Python словарь — коллекция пар ключ: значение с уникальными ключами.
Поиск по ключу ≈ O(1) благодаря хеш-таблице.

Python
students: dict[str, list[int]] = {
    'Аня':    [5, 4, 5],
    'Боря':   [3, 5, 4],
    'Наташа': [5, 5, 5],
    'Глеб':   [4, 3, 4],
    'Даша':   [5, 4, 3],
}
print(students['Наташа'])  # [5, 5, 5]

Если ключа нет — выбросится KeyError. Безопасно:

Python
print(students.get('Федя'))      # None
print(students.get('Федя', []))  # []  (значение по умолчанию)

Производительность

Поиск / вставка / удаление по ключу в среднем O(1).

CRUD-операции со словарём

Create / Update
phone_book = {
    'Маша':  '+7 911 987 65 43',
    'Артём': '+7 922 555 11 22',
}

phone_book['Юля']  = '+7 933 444 00 11'   # добавить
phone_book['Маша'] = '+7 900 777 88 99'   # обновить
setdefault - добавить, если нет
phone_book.setdefault('Юля', '+7 000 000 00 00')  # не изменит, т.к. уже есть
Read
print(phone_book['Маша'])          # значение
print('Юля' in phone_book)         # True
print(phone_book.keys())           # dict_keys([...])
print(phone_book.values())         # dict_values([...])
print(phone_book.items())          # пары (key, value)
Delete
removed = phone_book.pop('Маша', None)  # вернуть и удалить
phone_book.popitem()   # удалить последнюю пару (Python >=3.7 сохраняет порядок)
phone_book.clear()     # удалить всё

Итерация по словарю

Python
for name, phone in phone_book.items():
    print(f"{name}: {phone}")

Только ключи:

Python
for name in phone_book:
    ...

Только значения:

Python
for phone in phone_book.values():
    ...

Полезные методы

Метод Описание
dict.fromkeys(seq, value) создать словарь из ключей последовательности
update(other) добавить пары из другого словаря
pop(key, default) удалить и вернуть значение
get(key, default) безопасно получить значение

dict.fromkeys()

Создаёт новый словарь из последовательности ключей с одинаковым значением для всех:

Python
# Создаём словарь с одинаковыми значениями
keys = ['a', 'b', 'c']
default_dict = dict.fromkeys(keys, 0)
print(default_dict)  # {'a': 0, 'b': 0, 'c': 0}

# Полезно для инициализации счётчиков
letters = 'hello'
counter = dict.fromkeys(letters, 0)
print(counter)  # {'h': 0, 'e': 0, 'l': 0, 'o': 0}

update()

Добавляет пары ключ-значение из другого словаря или итерируемого объекта:

Python
user_info = {'name': 'Анна', 'age': 25}
additional_info = {'city': 'Москва', 'profession': 'Программист'}

# Объединяем словари
user_info.update(additional_info)
print(user_info)
# {'name': 'Анна', 'age': 25, 'city': 'Москва', 'profession': 'Программист'}

# Можно обновить существующие ключи
user_info.update({'age': 26, 'salary': 100000})
print(user_info)
# {'name': 'Анна', 'age': 26, 'city': 'Москва', 'profession': 'Программист', 'salary': 100000}

pop()

Удаляет элемент по ключу и возвращает его значение. Можно указать значение по умолчанию:

Python
inventory = {'яблоки': 50, 'бананы': 30, 'апельсины': 20}

# Удаляем и получаем значение
apples = inventory.pop('яблоки')
print(f'Продали {apples} яблок')  # Продали 50 яблок
print(inventory)  # {'бананы': 30, 'апельсины': 20}

# Безопасное удаление с значением по умолчанию
grapes = inventory.pop('виноград', 0)
print(f'Винограда было: {grapes}')  # Винограда было: 0

# Без значения по умолчанию вызовет KeyError, если ключа нет
# inventory.pop('киви')  # KeyError!

get()

Безопасно получает значение по ключу без риска получить ошибку:

Python
settings = {'theme': 'dark', 'language': 'ru', 'notifications': True}

# Безопасное получение значения
theme = settings.get('theme', 'light')  # 'dark'
font_size = settings.get('font_size', 14)  # 14 (значение по умолчанию)

print(f'Тема: {theme}')  # Тема: dark
print(f'Размер шрифта: {font_size}')  # Размер шрифта: 14

# Сравните с обычным обращением:
# print(settings['font_size'])  # KeyError!
print(settings.get('font_size'))  # None (если не указать default)

Когда использовать каждый метод:

  • dict.fromkeys() — для создания словаря с одинаковыми начальными значениями
  • update() — для объединения словарей или массового обновления
  • pop() — когда нужно удалить элемент и использовать его значение
  • get() — для безопасного чтения значений (избегает KeyError)
