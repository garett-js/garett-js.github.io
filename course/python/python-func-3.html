Локальные и глобальные переменные

Локальными называются переменные, объявленные внутри функции и доступные только ей самой. Код за пределами функции к ним доступа не имеет.

Локальные переменные

Рассмотрим функцию print_texas(), которая выводит информацию о количестве птиц в Техасе.

Python — Локальная переменная
def print_texas():
    birds = 5000
    print('В Техасе обитает', birds, 'птиц.')

Переменная birds создаётся внутри функции — это локальная переменная. К ней имеет доступ только код этой функции.

Локальные переменные невидимы снаружи

Python — Нет доступа к локальной переменной другой функции
def print_texas():
    birds = 5000
    print('В Техасе обитает', birds, 'птиц.')

def print_california():
    print('В Калифорнии обитает', birds, 'птиц.')

# NameError: name 'birds' is not defined

Функция print_california() пытается обратиться к локальной переменной birds из другой функции — возникает NameError.

Одинаковые имена в разных функциях

Python — Локальные одноимённые переменные
def print_texas():
    birds = 5000
    print('В Техасе обитает', birds, 'птиц.')

def print_california():
    birds = 9000
    print('В Калифорнии обитает', birds, 'птиц.')

Каждая функция видит только свою локальную birds.

Область видимости переменной

Область видимости — часть программы, в которой переменная доступна. Для локальной переменной — это функция, где она создана.

Python — Обращение до присваивания
def print_texas():
    print('В Техасе обитает', birds, 'птиц.')
    birds = 5000
# UnboundLocalError: local variable 'birds' referenced before assignment

Нельзя использовать локальную переменную до того, как ей присвоено значение.

Параметры — тоже локальные

Параметры функции доступны только внутри неё.

Python — Параметрические переменные
def draw_box(height, width):
    for i in range(height):
        print('*' * width)
# height, width — параметры; i — локальная переменная цикла

Память под локальные переменные выделяется на время выполнения функции (в стеке) и освобождается после её завершения.

Глобальные переменные

Глобальные переменные объявляются вне функций и доступны и основной программе, и функциям.

Python — Доступ к глобальной
birds = 5000  # глобальная переменная

def print_texas():
    print('В Техасе обитает', birds, 'птиц.')

def print_california():
    print('В Калифорнии обитает', birds, 'птиц.')

print_texas()
print_california()
# В Техасе обитает 5000 птиц.
# В Калифорнии обитает 5000 птиц.

Если внутри функции создать локальную переменную с тем же именем, она «затенит» глобальную.

Python — Затенение глобальной
birds = 5000  # глобальная переменная

def print_texas():
    birds = 1000  # локальная
    print('В Техасе обитает', birds, 'птиц.')

def print_california():
    birds = 7000  # локальная
    print('В Калифорнии обитает', birds, 'птиц.')

print_texas()
print_california()
# В Техасе обитает 1000 птиц.
# В Калифорнии обитает 7000 птиц.

Глобальные переменные — осторожно

Почему лучше избегать

  • Сложнее отлаживать: значение может менять любой участок кода.
  • Снижается переиспользуемость функций.
  • Ухудшается читаемость: зависимость от скрытого состояния.

Предпочитайте локальные переменные и передачу данных через параметры/возврат значений.

Глобальные константы

Глобальные константы допустимы. В Python их имитируют именами в UPPER_SNAKE_CASE и не меняют в коде.

Например, модуль math содержит math.pi и math.e.

Ключевое слово global

Чтобы присвоить значение глобальной переменной внутри функции, объявите её через global.

Python — Изменение глобальной из функции
def print_texas():
    global birds
    birds = 5000
    print('В Техасе обитает', birds, 'птиц.')

def print_california():
    print('В Калифорнии обитает', birds, 'птиц.')

print_texas()
print_california()
# В Техасе обитает 5000 птиц.
# В Калифорнии обитает 5000 птиц.
