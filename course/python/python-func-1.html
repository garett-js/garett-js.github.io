Функции в Python 1

Зачем нужны функции

В предыдущих уроках мы использовали встроенные в Python функции print(), input(), int(), str(), len() и многие другие. Пришло время начать писать свои собственные функции.

Мотивация: печать прямоугольника

В начале курса нужно было вывести звёздный прямоугольник 5×7 (5 строк и 7 столбцов).

Python — Наивный подход
print('*******')
print('*******')
print('*******')
print('*******')
print('*******')
Python — Повторение строки
print('*' * 7)
print('*' * 7)
print('*' * 7)
print('*' * 7)
print('*' * 7)
Python — Цикл
for _ in range(5):
    print('*' * 7)

Если нужно вывести три таких прямоугольника:

Python — Три прямоугольника
for _ in range(5):
    print('*' * 7)

print()

for _ in range(5):
    print('*' * 7)

print()

for _ in range(5):
    print('*' * 7)

Код работает, но повторяется. Изменение размера потребует правок в нескольких местах.

Вынос в функцию

Вынесем печать прямоугольника в функцию и будем вызывать её столько раз, сколько нужно.

Python — Объявление и вызов
def draw_box():
    for _ in range(5):
        print('*' * 7)

# Вызов функции
draw_box()

# Три прямоугольника
draw_box()
print()
draw_box()
print()
draw_box()

Код стал короче и читабельнее. При необходимости достаточно изменить логику внутри draw_box().

Именование функций

Имена функций назначаются как и имена переменных. Используйте описательные глаголы в стиле lower_case_with_underscores.

  • draw_box() — рисует прямоугольник
  • print_check() — печатает чек
  • calculate_gross_pay() — вычисляет зарплату до удержаний

Допустимы только латинские буквы, цифры и подчёркивание; имя не начинается с цифры; регистр важен.

Объявление функции

Функции объявляются с помощью ключевого слова def. После имени идут круглые скобки и двоеточие. Тело функции — блок с отступом.

Python — Скелет функции
def print_message():
    print('Я - Артур,')
    print('король британцев.')

# Вызов функции
print_message()

Объявление должно предшествовать вызову. Не забывайте вызывать функцию: просто определить — недостаточно.
