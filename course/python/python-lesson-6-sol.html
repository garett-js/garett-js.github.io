Задача № 2: Усиление оружия

Решение
win_count = int(input("Введите количество побед: "))

print(f"Победы: {win_count}")

# Проверяем, делится ли количество побед на 3 без остатка
if win_count % 3 == 0 and win_count > 0:
    print("Оружие усилено! (каждая 3-я победа)")

Задача № 4: Проверка числа на условия

Объяснение: Используем логический оператор and для проверки двух условий одновременно. Число нечетное, если number % 2 == 1, и делится на 7, если number % 7 == 0.

Задача № 5: Счастливый билет

Решение
ticket = input("Введите 6-значный номер билета: ")

# Проверяем, что введено ровно 6 цифр
if len(ticket) != 6 or not ticket.isdigit():
    print("Ошибка: введите ровно 6 цифр!")
else:
    # Разделяем на две половины
    first_half = ticket[:3]   # первые 3 цифры
    second_half = ticket[3:]  # последние 3 цифры
    
    # Вычисляем суммы
    sum_first = sum(int(digit) for digit in first_half)
    sum_second = sum(int(digit) for digit in second_half)
    
    # Проверяем равенство сумм
    if sum_first == sum_second:
        print(f"Да: {sum_first} равно {sum_second}")
        print("Поздравляем! У вас счастливый билет! 🍀")
    else:
        print(f"Нет: {sum_first} не равно {sum_second}")
        print("К сожалению, билет не счастливый.")

Задача № 6: Размен монет для великого воина

Решение
amount = int(input("Введите стоимость услуг: "))

# Номиналы монет в порядке убывания (жадный алгоритм)
denominations = [25, 15, 10, 1]
coins_used = []

original_amount = amount
total_coins = 0

print(f"\nРазбивка:")

for coin in denominations:
    if amount >= coin:
        # Вычисляем количество монет данного номинала
        count = amount // coin
        coins_used.append((coin, count))
        total_coins += count
        
        print(f"{count} монет номиналом {coin} = {count * coin}")
        
        # Уменьшаем оставшуюся сумму
        amount -= count * coin
    else:
        coins_used.append((coin, 0))
        print(f"0 монет номиналом {coin} = 0")

print(f"\nМинимальное количество монет: {total_coins}")

# Проверка правильности
total_value = sum(coin * count for coin, count in coins_used)
