Задача № 1: Удаление дубликатов

Уровень сложности: ⭐

Дан список emails с повторяющимися адресами. Ваша задача — создать новый список, содержащий только уникальные email-адреса из исходного.

Примерный вывод
Исходный список: ['user1@mail.ru', 'user2@mail.ru', 'user3@mail.ru', 'user1@mail.ru', 'user4@mail.ru']
Уникальные email: {'user4@mail.ru', 'user2@mail.ru', 'user3@mail.ru', 'user1@mail.ru'}

Подсказка: Помните, что при преобразовании списка в множество порядок элементов не сохраняется.

Задача № 2: Поиск общих друзей

Уровень сложности: ⭐⭐

У двух друзей есть списки их любимых фильмов, представленные в виде множеств. Напишите программу, которая найдёт и выведет фильмы, которые нравятся обоим друзьям (то есть общие фильмы).

Примерный вывод
Фильмы Алекса: {'Гарри Поттер', 'Матрица', 'Властелин колец', 'Звездные войны'}
Фильмы Анны: {'Матрица', 'Интерстеллар', 'Гарри Поттер', 'Начало'}
Общие любимые фильмы: {'Матрица', 'Гарри Поттер'}

Подсказка: Используйте операцию пересечения множеств (&).
