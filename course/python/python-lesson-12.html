Множества (Set) в Python

Главная фишка: только уникальные элементы

Представьте, что вы составляете список покупок. Если вы дважды добавите в него «молоко», вам всё равно нужно купить только одну упаковку. Множества в Python работают по тому же принципу: они автоматически избавляются от дубликатов.

Python
# Список с повторяющимися товарами
shopping_list = ['молоко', 'хлеб', 'яйца', 'молоко', 'масло', 'хлеб']
print(f"Обычный список: {shopping_list}")

# Превращаем список в множество, чтобы убрать дубликаты
unique_items = set(shopping_list)
print(f"Уникальные товары (множество): {unique_items}")
Вывод
Обычный список: ['молоко', 'хлеб', 'яйца', 'молоко', 'масло', 'хлеб']
Уникальные товары (множество): {'масло', 'хлеб', 'яйца', 'молоко'}

Основные операции (CRUD)

Работать с множествами просто. Вот как выполнять базовые действия: создать, прочитать, обновить и удалить элементы.

C - Create (Создание множества)

Сначала посмотрим на проблему дублирования в обычном списке, а затем решим её с помощью множества:

Python
# Список с повторяющимися играми
games_list = ['Minecraft', 'Dota 2', 'CS:GO', 'Minecraft', 'Valorant', 'CS:GO']
print(f"Список с дубликатами: {games_list}")

# Создаём множество из списка - дубликаты автоматически удаляются
games = set(games_list)
print(f"Множество (без дубликатов): {games}")

# Или создаём множество напрямую
favorite_games = {'Minecraft', 'Dota 2', 'CS:GO'}
print(f"Создали множество напрямую: {favorite_games}")

R - Read (Чтение из множества)

Python
# Проверяем, есть ли игра в множестве
if 'Minecraft' in games:
    print("✅ Игра 'Minecraft' есть в коллекции!")
else:
    print("❌ Игры 'Minecraft' нет в коллекции")

# Проверяем количество игр
print(f"Всего уникальных игр: {len(games)}")

# Перебираем все игры в множестве
print("Все игры в коллекции:")
for game in games:
    print(f"🎮 {game}")

U - Update (Обновление множества)

Python
# Добавляем одну игру
games.add('Valorant')
print(f"Добавили 'Valorant': {games}")

# Пытаемся добавить игру, которая уже есть (ничего не произойдёт)
games.add('Minecraft')
print(f"Попытались добавить 'Minecraft' снова: {games}")

# Добавляем несколько игр сразу
new_games = ['Cyberpunk 2077', 'The Witcher 3', 'Minecraft']
games.update(new_games)
print(f"Добавили несколько игр: {games}")

# Можно также объединить с другим множеством
indie_games = {'Hollow Knight', 'Celeste', 'Hades'}
games.update(indie_games)
print(f"Добавили инди-игры: {games}")

D - Delete (Удаление из множества)

Python
# remove() - удаляет элемент, но выдаёт ошибку, если его нет
games.remove('CS:GO')
print(f"Удалили 'CS:GO': {games}")

# discard() - удаляет элемент, но НЕ выдаёт ошибку, если его нет
games.discard('Fortnite')  # Этой игры нет в множестве, но ошибки не будет
print(f"Попытались удалить 'Fortnite' (безопасно): {games}")

# pop() - удаляет и возвращает случайный элемент
removed_game = games.pop()
print(f"Удалили случайную игру '{removed_game}': {games}")

# clear() - очищает всё множество
games_copy = games.copy()  # Сначала сделаем копию
games_copy.clear()
print(f"Очистили копию множества: {games_copy}")
print(f"Оригинальное множество осталось: {games}")
Вывод
Создали множество игр: {'CS:GO', 'Dota 2', 'Minecraft'}
Игра 'Minecraft' есть в коллекции!
Все игры в коллекции:
- CS:GO
- Dota 2
- Minecraft
Добавили игру: {'Valorant', 'CS:GO', 'Dota 2', 'Minecraft'}
Добавили еще несколько: {'Valorant', 'CS:GO', 'Dota 2', 'Minecraft', 'Cyberpunk 2077'}
Удалили игру: {'Valorant', 'Dota 2', 'Minecraft', 'Cyberpunk 2077'}
Попытались удалить 'Fortnite': {'Valorant', 'Dota 2', 'Minecraft', 'Cyberpunk 2077'}

Основные операции над множествами

Множества очень удобны для сравнения коллекций. Например, чтобы узнать, в какие игры играют ваши друзья.

Объединение (|) - Все игры вместе

Объединяет две коллекции игр в одну, убирая все дубликаты.

Python
my_games = {'CS:GO', 'Dota 2', 'Minecraft'}
friend_games = {'Cyberpunk 2077', 'Minecraft', 'The Witcher 3'}
all_games = my_games | friend_games
print(f"Все игры вместе: {all_games}")

Пересечение (&) - Общие игры

Находит игры, которые есть у обоих игроков.

Python
my_games = {'CS:GO', 'Dota 2', 'Minecraft'}
friend_games = {'Cyberpunk 2077', 'Minecraft', 'The Witcher 3'}
common_games = my_games & friend_games
print(f"Общие игры: {common_games}")

Разность (-) - Игры, которые есть только у меня

Показывает игры, которые есть у вас, но нет у вашего друга.

Python
my_games = {'CS:GO', 'Dota 2', 'Minecraft'}
friend_games = {'Cyberpunk 2077', 'Minecraft', 'The Witcher 3'}
unique_to_me = my_games - friend_games
print(f"Игры, которые есть только у меня: {unique_to_me}")

Симметрическая разность (^) - Уникальные игры для каждого

Находит игры, которые есть только у одного из вас (но не у обоих сразу).

Python
my_games = {'CS:GO', 'Dota 2', 'Minecraft'}
friend_games = {'Cyberpunk 2077', 'Minecraft', 'The Witcher 3'}
exclusive_games = my_games ^ friend_games
print(f"Уникальные игры для каждого: {exclusive_games}")
