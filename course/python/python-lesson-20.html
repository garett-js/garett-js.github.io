ООП. Часть 6: Ссылочная модель в Python

1. Копирование значений и ссылочная модель

В языке Python есть важное различие между типами данных:

  • Неизменяемые (immutable) типы ведут себя как значения 📦
  • Изменяемые (mutable) объекты передаются по ссылке 🔗

Неизменяемые типы в Python:

  • ✅ int, float, bool, str, tuple
  • ✅ frozenset, bytes
  • ✅ Enum (перечисления, о них поговорим позже)

Изменяемые типы в Python:

  • 🔗 list, dict, set
  • 🔗 bytearray
  • 🔗 Пользовательские классы (по умолчанию)

Копирование неизменяемых данных

Когда ты присваиваешь значение одной переменной в другую с неизменяемым типом, фактически создаётся ссылка на тот же объект, но поскольку объект неизменяемый, это выглядит как копирование.

👉 Неизменяемые типы ведут себя как отдельные значения!

Python
def main():
    a = 10
    b = a  # b получает ссылку на тот же объект int(10)
    print(f"a = {a}, b = {b}")  # a = 10, b = 10
    print(f"id(a) = {id(a)}, id(b) = {id(b)}")  # Одинаковые id!

    b = 20  # b теперь ссылается на новый объект int(20)
    print(f"a = {a}, b = {b}")  # a = 10, b = 20
    print(f"id(a) = {id(a)}, id(b) = {id(b)}")  # Разные id

if __name__ == "__main__":
    main()

Как работают ссылки в изменяемых объектах?

Изменяемые объекты (например, list, dict, set, пользовательские классы) не копируются, а передаются по ссылке. Это значит, что если одна переменная изменит объект, то изменения отразятся на всех переменных, которые ссылаются на этот объект.

👉 Пример с list (списками)

👉 Объект изменяется, потому что обе переменные указывают на одну область памяти!

Python
def main():
    list1 = [1, 2, 3]
    list2 = list1  # list2 получает ссылку на тот же объект!

    print(f"list1 = {list1}, list2 = {list2}")  # [1, 2, 3], [1, 2, 3]
    print(f"id(list1) = {id(list1)}, id(list2) = {id(list2)}")  # Одинаковые id

    list2[0] = 99  # Меняем элемент через list2

    print(f"list1 = {list1}, list2 = {list2}")  # [99, 2, 3], [99, 2, 3]

if __name__ == "__main__":
    main()

Даже если у объектов одинаковые данные (name), они хранятся в разных местах памяти, и Python считает их разными.

Операторы сравнения в Python:

  • == - сравнивает значения объектов (можно переопределить)
  • is - сравнивает идентичность объектов (ссылки на один объект)
  • id() - возвращает уникальный идентификатор объекта в памяти
Python
def comparison_demo():

    b = 1000

Как сравнить объекты по содержимому?

Чтобы сравнить объекты по их полям, нужно переопределить метод __eq__ и хеш-функцию __hash__.

Каждый объект в Python автоматически предоставляет целочисленный хэш-код через hash(). Однако можно переопределить метод __hash__, чтобы сгенерировать собственный. Если это сделать, нужно обязательно переопределить метод __eq__. Равные объекты (через ==) должны иметь одинаковые хэш-коды.

Python
class Player:
    def __init__(self, name: str):
        self.name = name

    def __eq__(self, other) -> bool:
        if self is other:
            return True
        if not isinstance(other, Player):
            return False
        return self.name == other.name

    def __hash__(self) -> int:
        return hash(self.name)
    
    def __repr__(self) -> str:
        return f"Player('{self.name}')"

def main():
    p1 = Player("Игрок")
    p2 = Player("Игрок")

    print(p1 == p2)  # True (сравниваем по имени)
    print(p1 is p2)  # False (разные объекты в памяти)
    
    # Теперь можно использовать в множествах и как ключи словарей
    players = {p1, p2}  # Множество содержит только один элемент
    print(f"Множество игроков: {players}")

if __name__ == "__main__":
    main()

👉 Существует два вида памяти Стек и Куча

В Стек попадают ссылки на объекты и локальные переменные функций. Здесь хранятся указатели на объекты, что позволяет быстро получить доступ к ним. Куча — это огромная область памяти, в которой создаются все объекты Python. Доступ в эту память имеется по всему приложению. Она работает медленнее + накладные расходы на работу "Сборщика Мусора"

В Python все данные являются объектами и хранятся в куче, но ссылки на них хранятся в стеке.

1. Stack (Стек) — для ссылок и локальных переменных

📌 Быстрая память, предназначенная для временных данных (ссылок на объекты).

Тут хранятся:

  • ✅ Ссылки на объекты (не сами объекты!)
  • ✅ Локальные переменные внутри функций
  • ✅ Аргументы функций

Как это работает?

  • Когда функция вызывается, все её ссылки на объекты попадают в Stack.
  • Когда функция завершает работу, ссылки удаляются из Stack.
  • Быстро, но мало памяти.
Python
def my_function():
    a = 10  # Ссылка на объект int(10) хранится в Stack
    b = 20.5  # Ссылка на объект float(20.5) хранится в Stack
    result = a + b  # Ссылка на объект float(30.5) хранится в Stack
    print(result)

def main():
    my_function()  # После выполнения ссылки a, b, result удалятся

if __name__ == "__main__":
    main()

✔ Ссылки на объекты живут только внутри своей функции, а потом исчезают.

2. Heap (Куча) — для всех объектов

📌 Большая память для хранения всех объектов Python.

Тут хранятся:

  • ✅ Все объекты без исключения (даже числа и строки!)
  • ✅ Данные, которые живут дольше функции

🔹 Объект хранится в Heap, а переменные p1 и p2 ссылаются на него!
🔹 Если объект больше не используется, Python удаляет его из памяти (Garbage Collection).

Python
class Player:
    def __init__(self, name: str):
        self.name = name

def main():
    p1 = Player("Игрок 1")  # Объект создаётся в Heap
    p2 = p1  # p2 получает ту же ссылку

    p2.name = "Изменённый Игрок"

    print(p1.name)  # "Изменённый Игрок" (оба указывают на один объект!)

if __name__ == "__main__":
    main()

2. Что такое static и где оно используется?

В Python аналогами static являются:

  • Переменные класса - относятся ко всему классу
  • @staticmethod - методы, не требующие экземпляра класса
  • @classmethod - методы, получающие класс как первый аргумент

Переменные класса:

Python

@staticmethod - статические методы:

Python
class MathUtils:
    """Утилитарный класс для математических операций"""
    
    @staticmethod
    def calculate_damage(attack: int, defense: int) -> int:
        """Расчёт урона (не требует экземпляра класса)"""
        return max(0, attack - defense)
    
    @staticmethod
    def calculate_distance(x1: float, y1: float, x2: float, y2: float) -> float:
        """Расчёт расстояния между точками"""
        return ((x2 - x1) ** 2 + (y2 - y1) ** 2) ** 0.5
    
    @staticmethod
    def is_critical_hit(chance: float) -> bool:
        """Проверка критического удара"""
        import random
        return random.random() < chance

def main():
    # Вызываем без создания экземпляра класса
    damage = MathUtils.calculate_damage(50, 20)
    print(f"Урон: {damage}")
    
    distance = MathUtils.calculate_distance(0, 0, 3, 4)
    print(f"Расстояние: {distance}")
    
    if MathUtils.is_critical_hit(0.2):
        print("Критический удар!")

if __name__ == "__main__":
    main()

@classmethod - методы класса:

class Character:

        self.hp = hp
        self.level = level

Различия между методами:

Python
class Example:
    class_var = "Я переменная класса"
    
    def __init__(self, value):
        self.instance_var = value
    
    def instance_method(self):
        """Обычный метод - нужен экземпляр"""
        return f"Экземпляр: {self.instance_var}"
    
    @classmethod
    def class_method(cls):
        """Метод класса - получает класс как первый аргумент"""
        return f"Класс: {cls.class_var}"
    
    @staticmethod
    def static_method():
        """Статический метод - не получает ни self, ни cls"""
        return "Статический метод"

def main():
    obj = Example("значение")
    
    # Все способы вызова
    print(obj.instance_method())     # Только через экземпляр
    print(obj.class_method())        # Через экземпляр или класс
    print(Example.class_method())    # Через класс
    print(obj.static_method())       # Через экземпляр или класс
    print(Example.static_method())   # Через класс

if __name__ == "__main__":
    main()

3. Перечисления Enum

Перечисления enum создаёт фиксированные наборы значений, удобные для работы со статусами, направлениями и режимами.

В Python для работы с перечислениями используется модуль enum.

Используются, когда есть фиксированный список возможных значений:

  • ✅ Направления (север, юг, запад, восток)
  • ✅ Дни недели (понедельник, вторник, …)
  • ✅ Статусы (loading, success, error)
Python
from enum import Enum

class Status(Enum):
    LOADING = "loading"
    SUCCESS = "success"
    ERROR = "error"

def check_status(status: Status) -> None:
    if status == Status.LOADING:
        print("⏳ Загружается...")
    elif status == Status.SUCCESS:
        print("✅ Успешно!")
    elif status == Status.ERROR:
        print("❌ Ошибка!")

def main():
    check_status(Status.LOADING)  # ⏳ Загружается...
    check_status(Status.SUCCESS)  # ✅ Успешно!

if __name__ == "__main__":
    main()

Enum с методами:

Python
from enum import Enum

class Planet(Enum):
    MERCURY = (3.303e+23, 2.4397e6)
    VENUS   = (4.869e+24, 6.0518e6)
    EARTH   = (5.976e+24, 6.37814e6)
    MARS    = (6.421e+23, 3.3972e6)
    
    def __init__(self, mass: float, radius: float):
        self.mass = mass       # в килограммах
        self.radius = radius   # в метрах
    
    @property
    def surface_gravity(self) -> float:
        # универсальная гравитационная постоянная
        G = 6.67300E-11
        return G * self.mass / (self.radius * self.radius)

from enum import Enum

Enum в играх:

Python
from enum import Enum, auto
from typing import Dict, List

class CharacterClass(Enum):
    WARRIOR = auto()
    MAGE = auto()
    ARCHER = auto()
    ROGUE = auto()

class AttackType(Enum):
    PHYSICAL = "physical"
    MAGICAL = "magical"
    RANGED = "ranged"

class Character:
    def __init__(self, name: str, char_class: CharacterClass):
        self.name = name
        self.char_class = char_class
        self.stats = self._get_base_stats()
    
    def _get_base_stats(self) -> Dict[str, int]:
        """Получить базовые характеристики в зависимости от класса"""
        stats_by_class = {
            CharacterClass.WARRIOR: {"hp": 150, "attack": 80, "defense": 70},
            CharacterClass.MAGE: {"hp": 80, "attack": 120, "defense": 40},
            CharacterClass.ARCHER: {"hp": 100, "attack": 90, "defense": 50},
            CharacterClass.ROGUE: {"hp": 90, "attack": 100, "defense": 45}
        }
        return stats_by_class[self.char_class]
    
    def get_attack_type(self) -> AttackType:
        """Получить тип атаки персонажа"""
        attack_types = {
            CharacterClass.WARRIOR: AttackType.PHYSICAL,
            CharacterClass.MAGE: AttackType.MAGICAL,
            CharacterClass.ARCHER: AttackType.RANGED,
            CharacterClass.ROGUE: AttackType.PHYSICAL
        }
        return attack_types[self.char_class]

def main():
    # Создание персонажей
    characters = [
        Character("Конан", CharacterClass.WARRIOR),
        Character("Гэндальф", CharacterClass.MAGE),
        Character("Леголас", CharacterClass.ARCHER),
        Character("Арагорн", CharacterClass.ROGUE)
    ]
    
    # Вывод информации
    for char in characters:
        attack_type = char.get_attack_type()
        print(f"{char.name} ({char.char_class.name}): "
              f"HP={char.stats['hp']}, "
              f"Attack={char.stats['attack']} ({attack_type.value})")

if __name__ == "__main__":
    main()

Уникальный декоратор для Enum:

Python
from enum import Enum, unique

@unique
class Color(Enum):
    RED = 1
    GREEN = 2
    BLUE = 3
    # CRIMSON = 1  # Это вызовет ValueError из-за @unique

def main():
    print("Все цвета уникальны!")
    for color in Color:
        print(f"{color.name} = {color.value}")

if __name__ == "__main__":
    main()

Преимущества Enum в Python:

  • ✅ Типобезопасность - нельзя передать неправильное значение
  • ✅ Автодополнение - IDE знает все возможные значения
  • ✅ Читаемость - код становится более понятным
  • ✅ Рефакторинг - легко изменить значения в одном месте
  • ✅ Итерация - можно перебрать все значения
  • ✅ Сравнение - безопасное сравнение значений

Enum помогает писать более надёжный и читаемый код, особенно в игровых проектах с множественными состояниями и типами объектов!
