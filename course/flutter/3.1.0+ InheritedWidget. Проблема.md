#### Что такое InheritedWidget и зачем он нужен

`InheritedWidget`  это фундаментальный механизм управления состоянием во Flutter, который позволяет эффективно передавать данные вниз по дереву виджетов без необходимости явной передачи через конструкторы у каждого виджета.

Этот мощный инструмент лежит в основе многих популярных решений для управления состоянием, включая Provider, и используется в таких встроенных виджетах Flutter, как Theme, MediaQuery и Localizations)

Например, до сих пор во всех наших приложениях мы передавали данные (свойства и методы) через конструктор в каждом виджете, пока не добирались до нужного.
Это очень трудоёмкий и не эффективный подход, особенно для больших приложений, где большой уровень вложенности виджетов.

1. Можно легко ошибиться
2. Утомительное занятие
3. Ухудшение производительности приложения, каждый виджет будет перерисовывать


Для демонстрации работы, пусть данные хранит самый верхний виджет `MyApp`
- Название карточки
- Метод для изменения текста

Эти данные будет принимать виджет далеко внизу по иерархии, и без использования `context` или `InheritedWidget`, данные придётся передавать через все вложенные виджеты.
Что конечно трудоёмко, много лишнего кода и ухудшение производительности, каждый раз вызывается метод `build` у всех виджетов!

class MyApp extends StatefulWidget {  
  const MyApp({super.key});  
  
  @override  
  State<MyApp> createState() => _MyAppState();

  // Пример для изменения состояния и передачи вниз по дереву виджетов

  void changeText() {  
    setState(() {

    });

  @override

      ),  
    );  
  }
